# 아군 2단계 전직 및 스킬 재구축 설계

## 목표

아군 직업 ID를 캐릭터 리소스 이름과 일치시키고, 레벨 5의 1차 분기 전직과 레벨 20의 2차 확정 전직을 지원한다. 총 20개 직업에 올바른 이미지와 전투 역할을 연결하며, 16개 전직 직업은 각자 고유한 액티브 스킬을 사용한다.

## 범위

- `AllyUnitData.json`을 4개 기본직과 16개 전직 직업 구조로 재작성한다.
- 최대 레벨을 30으로 변경한다.
- 전직 기준을 레벨 5와 20으로 확장한다.
- 합성, 전직 선택 UI, 자동 2차 전직, 상세 UI, 초상화 참조를 새 ID에 맞춘다.
- 대기, 이동, 기본 공격, 스킬 시전 애니메이션을 연결한다.
- 기존 8개 아군 스킬 구현을 제거하거나 교체하고 16개 전직 스킬을 구현한다.
- 적군 데이터와 적군 스킬은 변경하지 않는다.

## 직업 트리

```text
bear1 격투가
├─ bear2 격투가2
│  └─ bear4 곰버린
└─ bear3 닌자
   └─ bear5 강화 닌자

dog1 농부 검사
├─ dog2 전사
│  └─ dog4 강화 전사
└─ dog3 창병
   └─ dog5 강화 창병

cat1 궁수
├─ cat2 총잡이
│  └─ cat4 강화 총잡이
└─ cat3 석궁수
   └─ cat5 강화 석궁수

rabbit1 마법사
├─ rabbit2 힐러
│  └─ rabbit4 강화 힐러
└─ rabbit3 진화 마법사
   └─ rabbit5 진화 마법사2
```

## 데이터 구조

`AllyCommonData`는 단일 `classLevel` 대신 `firstClassLevel = 5`, `secondClassLevel = 20`, `maxLevel = 30`을 가진다. 각 `AllyUnitData`에는 해당 직업의 시작 레벨을 명시하는 `requiredLevel`을 추가한다.

- 기본직: `previousJob` 없음, `requiredLevel = 1`
- 1차 직업: 기본직 ID가 `previousJob`, `requiredLevel = 5`
- 2차 직업: 대응 1차 직업 ID가 `previousJob`, `requiredLevel = 20`

스탯 성장 시작점은 `requiredLevel`이다. 따라서 전직 직후부터 해당 직업의 기준 스탯과 성장량이 적용되며, 2차 직업이 레벨 5 기준으로 잘못 성장하는 문제를 방지한다.

## 합성 및 전직 흐름

동일 계보의 유닛 두 개를 합성하면 높은 쪽 레벨보다 1 높은 결과를 만든다.

- 결과 레벨 5, 두 입력이 기본직: 두 1차 직업을 선택 UI에 표시한다.
- 레벨 6~19: 선택한 1차 직업을 유지한다.
- 결과 레벨 20, 두 입력이 같은 1차 직업: 연결된 단일 2차 직업으로 자동 전직한다.
- 레벨 21~30: 2차 직업을 유지한다.
- 서로 다른 1차 분기 또는 서로 다른 2차 직업은 합성할 수 없다.
- 전직 완료 시 기존 진화 이펙트와 사운드를 재사용한다.
- 전직 후 현재 HP 비율을 새 최대 HP에 맞춰 유지한다.

## 스킬 설계

기본직은 기존처럼 마나와 액티브 스킬이 없다. 1차 및 2차 직업은 아래 고유 스킬을 사용한다.

| 직업 | 스킬 | 효과 |
|---|---|---|
| bear2 | 강철권 | 단일 강타 후 자신에게 보호막 |
| bear4 | 야성 폭주 | 주변 광역 피해, 체력 회복, 공격속도 증가 |
| bear3 | 그림자 베기 | 가장 먼 적에게 도약하고 큰 단일 피해 |
| bear5 | 분신 난무 | 후방 범위 연속 피해 후 잠시 피해 감소 |
| dog2 | 전투 함성 | 주변 피해 후 자신의 방어 능력 강화 |
| dog4 | 철벽 진형 | 전방 피해와 기절, 주변 아군 보호막과 피해 감소 |
| dog3 | 관통 돌진 | 직선 돌진, 경로 피해와 넉백 |
| dog5 | 초월 관통 | 긴 돌진, 방어 무시 피해와 다수 기절 |
| cat2 | 속사 | 단일 대상 연속 사격 후 공격속도 증가 |
| cat4 | 폭발 탄막 | 대상 주변에 다중 폭발 피해 |
| cat3 | 관통 사격 | 직선상의 다수 적에게 관통 피해 |
| cat5 | 필살 관통 | 긴 사거리, 높은 방어 무시, 뒤쪽 대상 추가 피해 |
| rabbit2 | 치유의 빛 | 체력이 가장 낮은 아군 단일 회복 |
| rabbit4 | 생명의 기도 | 주변 아군 광역 회복과 보호막 |
| rabbit3 | 폭발 화염구 | 범위 직접 피해와 지속 화상 |
| rabbit5 | 마력 폭풍 | 넓은 범위 피해, 기절 후 둔화 |

스킬 수치는 `AllyUnitData.json`의 `effects`가 소유한다. 스킬 클래스는 대상 선택과 효과 적용 방식만 담당한다. 기존 스킬 ID와 구현은 새 직업 의미에 맞는 ID와 구현으로 교체한다. 적군 스킬 레지스트리는 보존한다.

## 애니메이션

`EBattleUnitState`에 스킬 시전 상태를 추가한다. `BattleUnitVisual` 프로필은 `skillFrames`와 스킬 재생 속도를 지원한다.

- 기본직과 1차 직업: 전용 스킬 시트가 없으면 공격 프레임을 스킬 프레임으로 사용한다.
- 2차 직업: 각 `*_skill.png` 시트를 사용한다.
- 스킬 시전 시작 시 스킬 상태로 전환하고, 프레임 재생이 끝난 뒤 이전 전투 흐름으로 복귀한다.
- 실제 효과 적용 시점은 시전 애니메이션 안의 정규화된 타격 시점과 맞춘다.
- `AllyUnit.prefab`의 단일 `BattleUnitVisual` 프로필 배열에 20개 ID를 연결한다.
- 원본 스프라이트 방향과 기존 `flipX` 전투 방향 처리는 유지한다.

## UI 및 리소스 연결

- 진화 선택 UI는 레벨 5에서만 두 선택지를 표시한다.
- 레벨 20 자동 전직은 선택 UI를 열지 않는다.
- 상세 패널과 진화 선택 카드가 새 ID, 이름, 역할, 스킬 설명을 표시한다.
- 초상화는 기존 이미지 중 대응 가능한 항목을 새 ID에 매핑한다. 대응 초상화가 없는 직업은 해당 캐릭터의 정지 프레임을 사용한다.
- 원본 `.pxo` 파일은 런타임에서 참조하지 않는다.

## 오류 처리

- 전직 후보가 0개 또는 예상보다 많으면 합성을 취소하고 입력 유닛을 보존한다.
- 레벨 5에는 정확히 2개, 레벨 20에는 정확히 1개의 다음 직업이 있어야 한다.
- 스킬 ID가 레지스트리에 없으면 경고를 출력하고 마나를 소비하지 않는다.
- 필수 애니메이션 프레임이 없으면 정지 프레임으로 안전하게 표시하되 검증 테스트는 실패시킨다.

## 검증

- 데이터 계보에 순환이 없고 4개의 루트, 8개의 1차, 8개의 2차 직업이 존재하는지 검사한다.
- 레벨 5 선택 전직, 레벨 20 자동 전직, 레벨 30 합성 제한을 단위 테스트한다.
- 다른 분기의 합성이 거부되고 입력 유닛이 보존되는지 검사한다.
- 16개 스킬의 대상 선택, 피해, 회복, 보호막, 상태 효과를 단위 테스트한다.
- 20개 애니메이션 프로필과 필요한 프레임 참조를 Editor 테스트로 검사한다.
- Unity EditMode 전체 테스트와 컴파일을 실행한다.
- Game 씬에서 각 계열의 1차/2차 전직, 스킬 시전, 방향 전환, 풀 반환 후 재사용을 직접 확인한다.

## 제외 범위

- 적군 리소스와 적군 스킬 적용
- 스킬 이펙트 전용 프리팹의 완성형 연출
- 최종 밸런스 확정
- 이전 직업 ID 기반 저장 데이터 마이그레이션
