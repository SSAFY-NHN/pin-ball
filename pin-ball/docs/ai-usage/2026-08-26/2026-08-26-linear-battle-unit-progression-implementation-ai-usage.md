# 일직선 전투·공통 직업 성장 구현 AI 사용 기록

## 요청

- 유닛을 한 수평선에서만 이동시키고 양 진영 방어선에서 정확히 스폰한다.
- 이동 속도를 절반으로 낮추고 방어선 HP를 300으로 높인다.
- 준비 단계 맵 위에 기본 직업 공통 레벨 강화 패널을 표시한다.
- Lv.5/Lv.10에 상위 직업 구매 후보를 각각 해금한다.
- 콤보 표시를 정상화하고 최종 결과에서 핀볼 물리를 정지한다.
- 아이템 준비 단계 제한과 파란 아군 방어선은 유지한다.

## 구현

- 이동·넉백의 Y를 전투선으로 고정하고 랜덤 스폰 오프셋을 제거했다.
- 아군/적군 JSON 이동 속도를 정확히 50%로 낮추고 양 방어선 HP를 300으로 변경했다.
- `AllyProgressionController`에 Lv.1~10, `ceil(150 * 1.35^(level-1))` 비용, Lv.5/Lv.10 해금을 구현했다.
- 준비 단계·보유 여부·Gold를 검사해 공통 레벨을 올리고 보유 기본 직업과 이후 구매 유닛에 적용했다.
- 구매 후보를 기본 4종과 상위 8종으로 확장했다. 상위 직업은 잠금 상태에서도 표시하며 버튼만 비활성화된다.
- 맵 영역 위 `UnitUpgradePanel`과 기본 직업 카드 4개를 씬에 사전 배치했다.
- 콤보 UI를 단일 TMP 텍스트와 Filled Image 시간 게이지로 바꿨다.
- 최종 Victory/Defeat에서 `Time.timeScale` 없이 핀볼 속도·회전·시뮬레이션·자동 재생성을 정지한다.

- 나머지 5개는 작업 전 기준 실행에서도 존재한 기존 실패다.

- 준비 단계 아이템 구매/전투 중 비활성 규칙은 변경하지 않았다.
