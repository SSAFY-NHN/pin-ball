# PC WebGL 전체화면 성능 안정화 설계 AI 활용 기록

## 사용 도구/모델

- Codex (GPT-5 계열)
- 로컬 Git과 Unity 프로젝트 설정·코드 읽기
- Superpowers brainstorming과 investigate-first 절차

## 사용자 요청

- 새 기능보다 현재 게임 완성도와 최적화를 우선
- Chrome 2560×1440 전체화면에서 발생한 렉을 중점 개선
- 공 10개, 적 8명, 아군 5명과 2배속 조건 유지
- 성능을 신경 써 실제 PC WebGL 플레이를 안정화

## AI 제안 내용

- 1080p 창·전체화면과 1440p 전체화면을 동일 전투 조건으로 비교
- CPU, GPU, GC, 메모리, UI와 VFX 가설을 측정으로 분리
- GPU 픽셀 비용이 확인될 때만 1440p 전체화면 Render Scale 0.85 적용
- 부족한 경우에만 0.75 추가 검토
- 매 프레임 동적 해상도 대신 화면 조건 기반 품질 단계 사용
- UI 가독성과 입력 좌표를 성능과 별도로 검증
- 측정된 병목만 최소 범위로 수정

## AI 실제 수정 영역

- 기술 설계 문서 작성
- 본 AI 활용 기록 작성
- 런타임 코드, 테스트, 씬, 애셋과 ProjectSettings는 수정하지 않음

## 사용자 직접 결정 영역

- 현재 완성도와 PC WebGL 최적화를 다음 마일스톤으로 선택
- 1920×1080 60 FPS와 2560×1440 전체화면 목표 60 FPS 기준 승인
- Chrome 1440p 전체화면을 핵심 재현 환경으로 지정
- GPU 병목일 때 약간의 전장 선명도보다 안정적인 60 FPS 우선
- 1.0/0.85 화면 조건 품질 단계와 필요 시 0.75 검토 승인

## 중요 지시

- 추가 질문 없이 승인된 방향으로 진행
- 사용자 변경과 병행 중인 기지 스킬 구현 변경 보존
- 측정 전 추측 수정 금지
- 신규 외부 패키지와 요청 없는 리팩터링 금지

## 테스트/검증 결과

- Unity 6.0.0.79f1, URP Render Scale 1.0, HDR 활성, 2D Renderer 사용 확인
- WebGL 기본 크기, 메모리·압축 설정과 Chrome 대상 조건 확인
- Canvas 기준 해상도 1920×1080 확인
- 런타임 VSync 1, 목표 프레임 120 설정 확인
- 전투·UI·VFX의 프레임 갱신 경로 목록 확인
- 코드 변경이 없어 Unity 테스트와 Chrome 성능 측정은 아직 실행하지 않음

## 제한점/직접 확인 필요

- 현재 Chrome 빌드의 실제 FPS와 CPU/GPU 프레임 시간 기준선이 필요함
- WebGL Profiler 연결 가능 범위와 GPU 시간 가용성은 실제 빌드에서 확인해야 함
- 1440p Render Scale 0.85의 UI 선명도와 전장 화질을 사용자가 직접 비교해야 함
- 병행 기지 스킬 구현 완료 후 동일 커밋 기준으로 최종 회귀 측정해야 함
