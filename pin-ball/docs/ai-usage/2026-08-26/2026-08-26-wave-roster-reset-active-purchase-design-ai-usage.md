# 웨이브별 아군 초기화·전투 중 구매 설계 AI 활용 기록

## 사용 도구/모델

- Codex (GPT-5 계열)
- 로컬 Git 상태와 최근 커밋 확인

## 사용자 요청

- 웨이브마다 아군 초기화
- 웨이브 종료 시 유닛별 구매 횟수와 출격 쿨다운 초기화
- 증가한 구매 가격을 기본 가격으로 복구
- 유닛 구매는 `Active` 상태에서만 허용
- 유닛 없이 전투 시작 허용
- 골드는 웨이브 사이에 유지
- 경제 문제와 유닛 레벨 업그레이드는 후속 작업으로 연기

## AI 제안 내용

- 결과 표시 완료 시 기존 풀 회수 경로와 구매 상태 초기화를 함께 수행
- 구매 상태 검증을 `BattleManager`의 일반·무료 구매 공통 진입점에 배치
- 구매 횟수 초기화로 기본 가격을 자연스럽게 복구
- 새 런과 재도전을 포함한 모든 웨이브를 아군 0명으로 시작
- 골드와 전술 증원권은 초기화 대상에서 제외

## AI 실제 수정 영역

- 설계 문서 작성
- 게임 코드, 데이터와 씬은 수정하지 않음

## 사용자 직접 결정 영역

- 웨이브 종료 시 아군·구매 횟수·가격·쿨다운 초기화
- 골드 유지
- `Active`에서만 구매
- 아군 없이 웨이브 시작
- 준비 타이머와 경제 문제 후속 처리

## 중요 지시

- 현재 상성 강화 구현 변경 보존
- 구현 전 설계와 구현 계획 승인
- 이번 마일스톤을 초기화와 구매 상태 변경으로 제한

## 테스트/검증 결과

- 확정 규칙, 초기화 순서, 유지 상태, 테스트와 비범위를 자체 검토
- 코드 변경이 없어 Unity 테스트와 컴파일은 실행하지 않음

## 제한점/직접 확인 필요

- 현재 상성 강화 구현은 별도 작업 트리 변경으로 존재할 수 있으므로 구현 시작 전 Git 상태 재확인 필요
- 구현 후 첫 웨이브, 클리어, 재도전, 최종 승리와 패배에서 풀 회수 확인 필요
- 경제와 준비 단계의 무한 파밍 가능성은 이번 설계에서 해결하지 않음
