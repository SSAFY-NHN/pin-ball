# 체력 회복 포션 아이템 AI 사용 기록

## 사용 도구

- PixelLab MCP `pixen`
- Unity MCP/CLI (에셋 임포트, TextureImporter 설정, 컴파일 및 에셋 검증)
- Codex

## 사용자 요청

- 일반 체력 회복 포션과 전체 회복 포션 아이템 2종 제작
- 후속 요청에 따라 실제 체력 회복 기능은 구현하지 않음

## AI 제안 및 적용 내용

- 기존 64×64 아이템 아이콘 스타일에 맞춘 투명 배경 픽셀아트 포션 2종 생성
- 일반 포션은 붉은 원형 유리병, 전체 회복 포션은 금장과 발광 하트가 있는 상위 등급 병으로 구분
- `health_potion`, `full_health_potion` 데이터 및 enum 키 추가
- 기존 아이콘과 동일한 Sprite, Point 필터, 64 PPU 임포트 설정 적용

## 사용자 직접 결정 또는 추가 수정이 필요한 영역

- 실제 회복 대상, 회복량, 사용 시점과 소비성 아이템 처리 방식
- 상점 가격 및 최종 밸런스
- `DataTable/ItemDataTable.xlsx` 원본 동기화

## 프롬프트 및 생성 식별자

- 일반 포션: 작은 붉은 회복액 병, 천으로 감싼 코르크, 흰색 하트 문양, 64×64 투명 배경
  - PixelLab job: `061eeb40-c46e-48f6-94df-76dc76c430f2`
- 전체 회복 포션: 금장 마개와 장식, 빛나는 진홍색 회복액, 흰색 하트 및 마법 광휘, 64×64 투명 배경
  - PixelLab job: `0bef6697-7dcf-43ce-a0c2-c40880350fae`

## 검증

- Unity 6.0.0.79f1 프로젝트에 PNG 2종 임포트
- 두 에셋의 Sprite 타입, Point 필터, 투명도, 64 PPU 설정 확인
- 스크립트 재컴파일 오류 없음
- 실제 회복 기능은 사용자 요청에 따라 검증 범위에서 제외
