# 방어선 개체별 돌파 피해 AI 활용 기록

## 사용한 AI 도구/모델

- Codex
- GPT-5 계열 모델

## 사용자 요청

- 남은 마일스톤 1만 구현
- 아군 전멸 즉시 실패와 생존 적 피해 일괄 적용 제거
- 적이 씬 배치 방어선 Trigger에 실제 도달할 때 개체별 돌파 피해 적용
- 도달한 적 즉시 풀 회수 및 중복 피해 방지
- 방어선 HP가 0일 때만 같은 단계 재정비
- 골드, 업그레이드, 보유 아군, 현재 단계 유지
- 기존 적 성장 공식, 보스 규칙, 핀볼 시스템 유지

## AI 제안 내용

- Game 씬에 `DefenseLine` Trigger를 사전 배치하고 Inspector 참조 사용
- 아군 타깃이 없는 적은 기존 이동 계산을 재사용해 방어선으로 이동
- 피해 적용 후 roster 제거와 풀 반환을 수행해 마지막 적 판정 순서 보장
- 적 활성화 생명주기마다 돌파 소비 플래그를 초기화해 개체당 1회 피해 보장
- 방어선 HP가 0일 때 기존 실패 재정비 흐름을 재사용

## AI 실제 수정 영역

- 아군 수와 무관하게 적이 0일 때만 단계 클리어하도록 판정 변경
- `EnemyUnit`의 방어선 이동과 돌파 1회 소비 상태 추가
- `UnitManager`에 도달 적 단일 roster 제거 및 풀 반환 흐름 추가
- `BattleManager`에 개체별 돌파 피해, 누적 단계 피해, HP 0 실패 처리 추가
- 생존 적 돌파 피해 일괄 계산 제거
- Game 씬 `DefenseLine` Trigger 및 Inspector 참조 추가
- EnemyUnit 프리팹에 Trigger 감지용 Collider2D와 Kinematic Rigidbody2D 추가
- 직접 대응 EditMode 테스트 3개 추가

## 사용자 직접 결정/수정 필요 영역

- 기존 `BarrierReinforcement` 감소와 최소 피해를 적 개체별 돌파 피해에 적용
- DefenseLine의 최종 위치와 높이는 Unity Editor 직접 플레이에서 전장 연출에 맞게 확인 필요
- 마일스톤 2의 신규 아군 즉시 재투입 보강은 이번 범위에서 제외

## 중요한 프롬프트/지시

- 승인 전 코드와 씬 수정 금지
- 씬 사전 배치와 Inspector 참조 우선
- `[SerializeField]` 필드 underscore 금지
- 관련 없는 기존 변경 수정·복원 금지
- 전체 테스트, 전체 빌드, WebGL 빌드, 반복 검사 금지
- 자동 스테이징과 커밋 금지

## 테스트/검증 결과

- 구현 전 대상 테스트는 `EnemyUnit.TryConsumeBreach` 부재로 예상대로 컴파일 실패
- 구현 후 `DefenseLineBreachTests` 3개 통과
  - 아군 0명이고 적이 남은 상태에서 단계 미종료
  - 아군 수와 무관하게 적 0명에서 단계 클리어
  - 같은 활성화에서 적 돌파 피해 1회만 소비하고 재활성화 시 초기화
- 씬·프리팹 변경 후 추가 Unity 재실행은 사용자의 반복 검사 중단 지시에 따라 즉시 중단
- 전체 테스트, 전체 빌드, WebGL 빌드, PlayMode 직접 플레이는 수행하지 않음
