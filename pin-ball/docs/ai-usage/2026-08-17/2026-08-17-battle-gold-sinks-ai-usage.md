# 전투 골드 소비처 AI 활용 기록

## 사용 도구와 모델

- OpenAI Codex, GPT-5 계열
- 로컬 파일 검색, 패치 편집, Git diff 정적 확인

## 사용자 요청

공용 골드를 사용하는 기본 유닛 구매, 전체 아군 공격력 강화, 방어선 체력 강화와 세 행의 씬 배치 UI를 구현한다. 자동·플레이 테스트와 불필요한 검사는 수행하지 않는다.

## AI 제안

- `BattleManager`가 구매를 조율하고 하위 `BattleUpgradeController`가 레벨·비용·효과를 계산한다.
- 공용 공격 배율은 아이템 배율과 단일 재계산 경로에서 합성한다.
- 전투 상태에 따라 구매 유닛의 현재 단계 참가 여부를 나눈다.

## AI 실제 수정 영역

- 전투 업그레이드 런타임 데이터와 비용 계산
- 골드 차감, 최대 판정, 구매 성공 이벤트
- 유닛 구매와 보유·활성 목록 처리
- 공용 공격 배율 합성
- 방어선 최대·현재 HP 증가
- Game 씬의 전투 업그레이드 UI 세 행과 Inspector 참조
- 승인 설계와 구현 계획 문서

## 사용자 결정 영역

- A안인 `BattleManager` 직접 연결 구조 승인
- 불필요한 검사와 자동·플레이 테스트 제외
- 실제 플레이 밸런스와 최종 UI 배치 감각은 Unity에서 직접 확인 필요

## 중요 지시

- 기존 핀볼 생산, 자동 단계 진행, 적 성장과 관련 없는 변경 보존
- `[SerializeField]` 이름에 underscore 미사용
- 씬 배치 UI와 기존 풀링 흐름 우선
- 새 외부 패키지와 테스트 파일 금지

## 정적 확인 결과

- 구매 성공 후 보유 아군 추가, 최대 5명 거부, Spawn·슬롯 실패 시 골드 보존 경로 확인
- 현재·미래 아군 공용 공격 배율과 단계 복구 시 재계산 경로 확인
- 방어선 최대·현재 HP 동량 증가와 새 런 초기화 경로 확인
- 골드 부족 시 구매 진입 전 거부 경로 확인
- Game 씬의 버튼·이름·레벨·효과·비용 참조 확인

테스트, 플레이 검증과 Unity 컴파일은 사용자 요청에 따라 실행하지 않았다.
