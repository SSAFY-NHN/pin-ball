# 지속형 자동전투 루프 AI 활용 기록

## 사용한 AI 도구/모델

- OpenAI Codex
- Unity 6.0.0.79f1 배치 모드

## 사용자 요청

기존 전투 준비, 시작 버튼과 유한 웨이브 결과 흐름을 제거하고 핀볼 생산과 동시에
자동 시작·다음 단계 진행·같은 단계 재정비가 이어지는 최소 지속형 자동전투 루프를 구현한다.

## AI 제안 내용

- 기존 전투 유닛과 풀링 계층은 유지한다.
- `BattleManager` 하위 Controller가 단계 상태와 적 수 공식을 담당한다.
- 기존 `PlayerHp`는 첫 프로토타입 방어선 HP로 재사용한다.
- 아군 전투 사망과 영구 보유 해제를 분리한다.
- 수작업 10웨이브와 Victory/Defeat 결과 흐름은 지속 단계 코어에서 제거한다.

## AI 실제 수정 영역

- 지속 단계 상태와 자동 시작·전환·재정비 흐름
- 공식 기반 적 수와 지수형 체력·공격력 성장
- 남은 적 풀 회수와 보유 아군 전투 상태 복구
- Game 씬 시작 아군 및 단계 프로토타입 설정
- 현재 단계, 방어선 HP와 전환 상태 UI
- 기존 시작 버튼, 수동 발사 UI, 유한 웨이브 HUD와 결과 화면 비활성화
- 제거된 유한 웨이브 상태에만 종속되던 코드와 테스트 정리

## 사용자 직접 결정/확인 필요 영역

- 체력 성장률 12%, 공격 성장률 8%와 적 수 증가 구간의 실제 플레이 밸런스
- 기본 적을 `goblin` 하나로 유지할 기간
- 실제 방어선 오브젝트 및 개별 돌파 판정을 후속 마일스톤에 추가할지 여부
- Game 씬에서 전투와 핀볼 보드의 최종 동시 가시성

## 중요한 지시

- 테스트 우선으로 구현하지 않는다.
- 기능 확인과 무관한 검사나 검사를 위한 검사를 하지 않는다.
- 핀볼 물리, 생산 업그레이드, 범퍼 VFX/SFX를 변경하지 않는다.
- 성장 손실과 Title 씬 이동 없이 같은 단계로 재정비한다.

## 테스트/검증 결과

- 신규 테스트와 전체 테스트는 실행하지 않았다.
- Unity 배치 모드에서 스크립트 컴파일 성공을 확인했다.
- 컴파일 오류는 없었다.
- 기존 PinballManager의 비활성 수동 발사 API 관련 경고 4건은 유지된다.
- Game 씬 직접 플레이 검증은 실행하지 않았으며 사용자가 Editor에서 핵심 흐름을 확인해야 한다.
