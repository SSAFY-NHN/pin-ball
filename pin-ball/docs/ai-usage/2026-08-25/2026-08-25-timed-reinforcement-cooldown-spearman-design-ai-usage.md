# 시간표 증원·출격 쿨다운·창병 설계 AI 활용 기록

## 사용 도구/모델

- Codex (GPT-5 계열)
- 로컬 파일 검색과 Git 상태 확인

## 사용자 요청

- 냥코대전쟁을 참고해 현재 게임의 전투 판단과 압박 강화
- 고정 시간표 출현 후에도 전투가 끝날 때까지 적 증원
- 장기 파밍 문제를 막기 위해 60초부터 강화 증원, 90초부터 강한 조합 반복
- 유닛별 출격 쿨다운 추가
- 기존 창병을 네 번째 구매 유닛으로 추가
- 전선 위험 UI 대신 공세 전환 카운트다운 초시계 추가

## AI 제안 내용

- 초기 고정 시간표, 기본 증원, 강화 증원과 최후 공세의 단계형 출현 구조
- 동시 생존 적 8명 제한과 누적 대기열 없는 출현 보류
- 구매 성공 후에만 시작되는 유닛별 독립 쿨다운
- 기존 `spearman` 데이터와 리소스를 재사용한 창병 구매 카드
- 실제 공세 경과 시간을 공유하는 60초·90초 카운트다운 UI

## AI 실제 수정 영역

- 설계 문서 작성
- 게임 코드, 데이터와 씬은 수정하지 않음

## 사용자 직접 결정 영역

- 고정 시간표 이후 증원 지속
- 60초부터 강화 증원
- 90초부터 강한 조합 반복
- 출격 쿨다운 적용
- 창병 추가
- 전선 위험 UI 제외
- 공세 카운트다운 UI 추가

## 중요 지시

- 기존 구조와 동작 보존
- 구현 전 설계와 계획 승인
- 씬 배치 UI와 기존 리소스 우선 사용

## 테스트/검증 결과

- 문서의 확정 규칙, 데이터 흐름, UI, 테스트와 비범위를 자체 검토
- 코드 변경이 없어 Unity 테스트와 컴파일은 실행하지 않음

## 제한점/직접 확인 필요

- 웨이브별 실제 초기·증원 조합과 간격은 구현 계획에서 현재 적 데이터에 맞춰 구체화 필요
- 구현 후 60초와 90초 공세 전환의 체감 난이도 플레이 테스트 필요
- Game 씬의 네 카드 배치와 WebGL 해상도 가독성 확인 필요
