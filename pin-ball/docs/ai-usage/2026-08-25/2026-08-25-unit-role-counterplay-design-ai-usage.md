# 유닛 역할 상성 강화 설계 AI 활용 기록

## 사용 도구/모델

- Codex (GPT-5 계열)
- 로컬 코드·데이터 검색과 Git 상태 확인

## 사용자 요청

- 시간표 공세와 출격 쿨다운 다음 마일스톤 진행
- 전사, 궁수, 마법사와 창병의 선택 이유 강화
- 별도 속성 태그보다 행동·능력치 기반 상성 사용

## AI 제안 내용

- 전사는 돌진 저지와 전열 방어 유지
- 궁수는 장거리 단일 지속 피해 유지
- 마법사 계열 기본 공격에 제한된 범위 피해 추가
- 창병 계열 기본 공격에 방어력 일부 무시 추가
- 10웨이브를 네 역할의 소개와 종합 시험 순서로 재편
- 구매 카드 역할 문구로 행동 차이 설명

## AI 실제 수정 영역

- 설계 문서 작성
- 게임 코드, 데이터와 씬은 수정하지 않음

## 사용자 직접 결정 영역

- 행동·능력치 기반 상성 선택
- 마법사 범위 공격과 창병 방어 관통 승인
- 전사·궁수에 새 특수 행동을 추가하지 않음
- 역할 중심 10웨이브 학습 순서 승인
- 상성 아이콘과 속성표 제외

## 중요 지시

- 이전 마일스톤의 미커밋 구현 변경 보존
- 구현 전 설계와 구현 계획 승인
- 기존 구조와 동작을 최소 변경으로 유지

## 테스트/검증 결과

- 현재 아군·적 데이터, 적 스킬과 기본 공격 경로를 정적으로 확인
- 설계의 계열 목록, 공격 규칙, 웨이브 목표, 회귀 범위와 비범위를 자체 검토
- 코드 변경이 없어 Unity 테스트와 컴파일은 실행하지 않음

## 제한점/직접 확인 필요

- 이전 시간표 공세·쿨다운 구현은 현재 작업 트리에 미커밋 상태로 존재함
- 구현 전 이전 마일스톤의 테스트 통과 여부와 실제 데이터 타입을 다시 확인해야 함
- 구현 후 마법사 범위 반경 1.5, 보조 피해 60%, 창병 방어 무시 40%를 플레이 테스트로 조정해야 함
- 네 유닛 구매 선택률과 웨이브별 실패 원인을 지표 또는 수동 기록으로 확인해야 함
