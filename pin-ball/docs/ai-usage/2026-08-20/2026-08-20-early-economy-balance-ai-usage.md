# 초기 경제 밸런스 조정 AI 사용 기록

- 사용 도구/모델: Codex
- 사용자 요청: 초반 골드 획득과 아군 구매 진행 속도 개선
- AI 제안: 범퍼 기본 수익을 높이고 첫 수익 강화, 아군 구매, 공 추가 비용을 낮춤
- 실제 수정: 범퍼 기본 수익 3G, 수익 강화 기본 비용 15G, 아군 구매 기본 비용 50G, 공 추가 기본 비용 100G
- 사용자 결정: 제안된 네 가지 초기 밸런스 값 적용 승인
- 주요 프롬프트/지시: "돈이 너무 안벌린다", "ㄱㄱ"
- 검증: 씬 직렬화 값과 `git diff --check` 확인
- 직접 확인 필요: Unity Play Mode에서 첫 강화 및 첫 아군 구매까지 걸리는 실제 시간
