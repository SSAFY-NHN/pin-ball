# 프로젝트 문서 구조 정리 AI 활용 기록

- 사용한 AI 도구/모델: OpenAI Codex (GPT-5 계열)
- 사용자 요청: 저장소 곳곳에 흩어진 Markdown 문서의 수정 필요 내용을 반영하고 목적별 폴더로 정리.
- AI 제안 내용: 기술 설계, 구현 계획, AI 활용 기록을 날짜별 디렉터리로 분류하고 콘텐츠·인계 문서를 별도 폴더에 배치. `.github`에는 플랫폼이 직접 사용하는 지침만 유지. 문서 색인과 저장 규칙을 추가하고 최신 M2~M8 설계에 구현 상태와 커밋을 기록.
- AI 실제 수정 영역: `docs/designs`, `docs/plans`, `docs/ai-usage`, `docs/content`, `docs/handbook`으로 기존 문서를 이동하고 `docs/README.md` 추가. `.github`의 일반 지침·과거 계획·누적 AI 로그를 해당 문서 폴더로 정리하고 중복 인계 문서를 제거. 이동으로 낡은 내부 경로를 수정하고 `AGENTS.md`, Copilot 지침과 프로젝트 원문 프롬프트에 현재 작업·검증·문서 위치 규칙을 동기화.
- 사용자 직접 결정/수정 필요 영역: 없음. 루트 `AGENTS.md`, `.github/copilot-instructions.md`, `.github/project-master-prompt.md`는 Agent 진입 규칙과 플랫폼 지침이므로 기존 위치를 유지.
- 중요한 프롬프트/지시: 설계를 먼저 커밋한 뒤 바로 구현. 검사와 검사를 위한 검사는 실행하지 않음.
- 테스트/검증 결과: 사용자 지시에 따라 테스트, 빌드, Unity 실행, 문서 검사기, 링크 검사기와 정적 분석을 수행하지 않음. 이동 대상과 Markdown의 직접 경로 참조는 문서 내용을 읽어 확인함.
