# 유닛 구매 카드와 전술 증원권 UI AI 활용 기록

## 사용한 AI 도구/모델

- Codex
- GPT-5 계열 모델

## 사용자 요청

- 전사, 궁수와 마법사의 역할, 현재 비용과 현재 보유 수를 비교하는 구매 카드 연결
- 전술 증원권 보유 시 카드 비용을 무료로 표시하고 `다음 유닛 무료` 공용 안내 표시
- 증원권 획득과 소비, 골드, 아군 상한과 게임 오버 상태를 기존 정책에 맞춰 즉시 갱신
- 씬 사전 배치와 Inspector 참조 유지

## AI 제안 내용

- 카드별 Controller 대신 세 카드를 한 번에 갱신하는 단일 패널 Controller 사용
- 구매 가능 여부는 `BattleManager.CanPurchaseAlly`를 그대로 사용
- 카드의 현재 보유 수는 정확히 같은 기본 유닛 ID의 살아 있는 아군만 집계
- 기존 비활성 구매 비용 텍스트를 전술 증원권 공용 안내로 재사용

## AI 실제 수정 영역

- 세 구매 카드의 버튼, 역할, 비용, 보유 수와 무료 상태 표시 연결
- 증원권, 골드, 전투 상태와 아군 보유 수 변경 이벤트에 따른 패널 갱신
- 유닛 ID별 현재 보유 수 조회와 아군 사망 시 보유 수 변경 알림 보완
- Game 씬의 전사 버튼 분리와 공용 `다음 유닛 무료` 안내 배치
- 관련 Controller, 보유 수와 씬 참조 EditMode 테스트 갱신

## 사용자 직접 결정/수정 필요 영역

- Unity Editor 직접 플레이로 실제 화면 간격과 버튼 클릭 영역 확인
- 증원권 획득, 무료 Spawn 성공 및 실패 상황에서 표시 전환 확인

## 중요한 프롬프트/지시

- `OnGUI`와 런타임 UI 자동 생성 금지
- 전투 및 핀볼 도메인 로직을 UI에 복제하지 않음
- 관련 없는 씬 오브젝트, 애니메이션과 VFX 변경 금지
- 전체 테스트, 전체 빌드, WebGL 빌드와 장시간 플레이 검사 금지
- 자동 스테이징 및 커밋 금지

## 테스트/검증 결과

- 관련 런타임 스크립트와 EditMode 테스트 코드는 Unity 응답 파일 기반 Roslyn 컴파일로
  오류 없이 통과했다. 기존 `PinballManager` 미사용 이벤트 및 필드 경고 4건만 확인했다.
- 지정한 EditMode 테스트만 Unity Test Runner로 실행하려 했으나 테스트 시작 전 로컬
  Licensing Client 초기화 시간 초과가 발생해 실행 결과를 얻지 못했다.
- 전체 테스트, 전체 빌드, WebGL 빌드와 장시간 플레이 검사는 실행하지 않았다.
