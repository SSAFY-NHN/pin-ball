# 전술 증원권 도메인 흐름 AI 활용 기록

## 사용한 AI 도구/모델

- Codex
- GPT-5 계열 모델

## 사용자 요청

- 큰 범퍼 콤보 또는 잭팟으로 최대 1개의 전술 증원권 획득
- 다음 선택 유닛을 무료로 Spawn하고 성공 뒤에만 증원권 소비
- 무료 Spawn도 해당 유닛 구매 성공 횟수에 반영
- 콤보 구간당 한 번만 지급하고 콤보 초기화 뒤 재획득 허용
- 최종 UI와 연출은 제외

## AI 제안 내용

- `TacticalReinforcementController`가 증원권과 콤보 구간 상태를 단독 소유
- `BattleManager`가 `PinballManager` 이벤트 구독과 무료 구매 조율 담당
- 기존 콤보 최대 배율 및 잭팟 기준과 같은 기본 기준값 5 사용
- 마일스톤 3 UI를 위한 단일 상태 변경 이벤트 제공

## AI 실제 수정 영역

- 증원권 획득, 중복 방지, 콤보 초기화, 소비 상태 구현
- 기존 콤보 및 잭팟 이벤트 구독·해제 연결
- 무료 유닛 Spawn과 성공 횟수 기록 경로 추가
- Spawn 성공 뒤에만 증원권을 소비하는 원자적 사용 계약 추가
- 콤보 기준값 씬 직렬화
- 관련 EditMode 테스트와 기존 잭팟 골드 보상 특성 테스트 추가

## 사용자 직접 결정/수정 필요 영역

- 마일스톤 3에서 증원권 보유 표시와 구매 카드 무료 상태 연결
- 플레이 관찰에 따른 콤보 기준값 조정

## 중요한 프롬프트/지시

- 기존 `OnComboChanged`, `OnJackpotTriggered` 우선 재사용
- 전술 증원권 외 직접 공격, 버프와 공 복제 금지
- 전체 테스트, 전체 빌드, WebGL 빌드와 장시간 플레이 검사 금지
- 자동 스테이징 및 커밋 금지

## 테스트/검증 결과

- 관련 런타임 스크립트와 EditMode 테스트 코드를 Unity 응답 파일 기반
  Roslyn 컴파일로 검사했으며 오류 없이 통과했다. 기존 미사용 이벤트 및 필드
  경고 4건만 확인했다.
- 지정한 EditMode 테스트만 Unity Test Runner로 실행하려 했으나, 테스트 시작 전
  로컬 Licensing Client 연결 시간 초과가 반복되어 실행 결과를 얻지 못했다.
- 전체 테스트, 전체 빌드, WebGL 빌드와 장시간 플레이 검사는 실행하지 않았다.
