# 핀볼 생산 업그레이드 구현 계획
## 목표

자동 공 순환과 BigBumper 기본 골드 위에 범퍼 수익, 영구 공 추가, 공급 속도 업그레이드를 연결한다.

## 구현 순서

1. 비용·레벨·최소 재생성 시간 계산을 EditMode 테스트로 정의한다.
2. 영구 공 슬롯과 Split Capsule 복제 공 풀을 분리한다.
3. `PinballManager`가 공용 골드 구매, 범퍼 수익, 공별 예약을 조율하게 한다.
4. Game 씬에 영구 공 10개, 복제 공, 씬 배치 Button/TMP UI를 연결한다.
5. 수동 발사·발사 비용·구형 튜토리얼 연결을 비활성화하고 BoardGlow 계층을 정상화한다.
6. 관련 EditMode 테스트, Unity 컴파일, Game 씬 직접 플레이만 확인한다.

## 확정 규칙

- 비용은 `CeilToInt(기본 비용 * 비용 배율 ^ 현재 레벨)`이다.
- 범퍼 수익은 1G에서 레벨당 1G 증가한다.
- 영구 공은 1개로 시작하고 최대 10개다.
- 재생성은 3초에서 레벨당 0.25초 감소하며 최소 0.75초다.
- 공급 속도는 이미 예약된 공에 소급 적용하지 않는다.
- 복제 공은 영구 슬롯과 예약에 들어가지 않는다.
- 시작 골드는 0이다.
