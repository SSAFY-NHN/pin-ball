# 전투 골드 소비처 구현 계획

## 목표

기존 공용 골드와 유닛 풀링을 이용해 유닛 구매, 전체 공격력, 방어선 체력의 세 소비처와 씬 배치 UI를 연결한다.

## 작업

- [x] `BattleUpgradeController`와 Inspector 설정 데이터를 추가한다.
- [x] `BattleRunState`에 최대 HP 증가와 동량 회복 연산을 추가한다.
- [x] `UnitBase`의 아이템·공용 공격 배율을 단일 재계산 경로로 합성한다.
- [x] `UnitManager`에 최대 인원, Spawn 실패, 상태별 참가 처리를 포함한 구매 경로를 추가한다.
- [x] `BattleManager`에 구매 조회·실행 API와 변경 이벤트를 추가한다.
- [x] 전투 업그레이드 UI Controller와 Game 씬의 세 행을 연결한다.
- [x] 코드와 씬 직렬화를 읽어 요청된 실패·유지 경로를 정적으로 확인한다.
- [x] 마일스톤 전용 AI 활용 기록을 작성한다.

## 검증 제한

새 테스트 작성, EditMode·PlayMode·전체 테스트 실행, 자동 플레이 스크립트와 임시 Editor 검사 코드는 사용하지 않는다. Unity 컴파일은 필요성이 명확할 때 한 번만 수행한다.
