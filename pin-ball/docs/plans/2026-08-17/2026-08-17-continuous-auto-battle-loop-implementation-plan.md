# 지속형 자동전투 루프 구현 계획

## 목표

핀볼 생산을 중단하지 않고 전투가 자동 시작되고, 적 전멸 시 다음 단계로 진행하며,
아군 전멸 시 성장 손실 없이 같은 단계로 재진입하는 최소 지속형 전투 루프를 만든다.

## 구현 범위

- `BattleManager`는 런 경제, 방어선 HP와 공개 이벤트를 유지한다.
- `BattleStageController`는 `Starting`, `Active`, `Advancing`, `Recovering` 상태와 단계 번호를 관리한다.
- `EnemyStageScalingController`는 구간별 적 수 증가와 최대 적 수를 계산한다.
- 적 체력과 공격력은 기존 적 데이터의 성장률을 지수 배율로 적용한다.
- `UnitManager`는 공식 결과에 따라 적을 생성하고 전환 시 적을 풀로 회수한다.
- 전투 중 사망한 아군은 보유 목록에 유지하고 단계 시작 시 위치와 전투 상태를 복구한다.
- Game 씬의 Inspector 시작 아군 데이터를 사용해 첫 전투에 필요한 기본 아군을 준비한다.
- 기존 시작 버튼, 수동 발사 UI, 유한 웨이브 HUD와 Victory/Defeat 결과 화면은 사용하지 않는다.
- 상태 UI는 현재 단계, 방어선 HP와 전환/재정비 문구만 표시한다.

## 작업 순서

- [x] 유한 웨이브 상태를 지속 단계 상태로 교체한다.
- [x] 단계 전환 중 중복 처리를 차단하는 Controller를 연결한다.
- [x] 공식 기반 적 수와 지수형 적 스탯 성장을 적용한다.
- [x] 아군 전투 사망과 영구 보유 해제를 분리한다.
- [x] 단계 종료 시 적 회수 및 아군 재정비를 연결한다.
- [x] Game 씬에 시작 아군과 단계 설정을 직렬화한다.
- [x] 기존 전투 시작/결과 UI를 비활성화하고 최소 단계 UI를 연결한다.
- [x] Unity 스크립트 컴파일을 확인한다.

## 제외 범위

- 유닛 구매와 아군 공격력 업그레이드
- 방어선 체력 구매
- 실제 방어선 오브젝트를 향한 적 이동 및 개별 돌파 판정
- 보스, 저장 형식, 영구 성장, 오프라인 보상
- 핀볼 물리와 범퍼 VFX/SFX 변경
- 기능 구현을 위한 목적이 없는 테스트 추가 또는 전체 검사

## 직접 확인 항목

1. Game 씬 진입 후 입력 없이 1단계가 시작되는지 확인한다.
2. 적 전멸 후 전환 문구가 표시되고 2단계가 한 번 생성되는지 확인한다.
3. 아군 전멸 후 단계 번호를 유지하고 같은 아군이 재정비되는지 확인한다.
4. 실패 전후 골드와 생산 업그레이드가 유지되는지 확인한다.
5. Active, Advancing, Recovering 모든 상태에서 공 순환과 범퍼 골드가 계속되는지 확인한다.
