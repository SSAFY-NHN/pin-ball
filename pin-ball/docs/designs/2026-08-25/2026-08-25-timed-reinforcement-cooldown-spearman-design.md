# 시간표 증원·출격 쿨다운·창병 설계

## 1. 목적

현재 고정 웨이브 전투에 냥코대전쟁을 참고한 출격 판단과 장기전 압박을 추가한다. 적은 초기 고정 시간표 이후에도 증원되며, 60초와 90초에 공세가 강화된다. 아군 구매에는 유닛별 출격 쿨다운을 적용하고 기존 창병 리소스를 네 번째 구매 선택지로 연결한다.

핀볼 생산과 전투는 계속 동시에 진행한다. 장기전에서 골드 획득을 막지 않고, 시간이 지날수록 강한 적 조합을 투입해 의도적인 지연의 이득을 상쇄한다.

## 2. 확정 규칙

- 웨이브는 준비 단계에서 사용자가 시작한다.
- 웨이브 시작 시 초기 고정 시간표를 실행한다.
- 초기 시간표가 끝나고 적 방어선이 살아 있으면 기본 증원을 반복한다.
- 웨이브 시작 60초 후 강화 증원으로 전환한다.
- 웨이브 시작 90초 후 최후 공세로 전환한다.
- 적 능력치를 시간에 따라 무한 증가시키지 않고, 단계별로 정의된 적 조합을 반복한다.
- 동시 생존 적 상한은 8명이다.
- 상한에 도달하면 출현을 보류하고 빈자리가 생긴 뒤 다음 출현 시점에 재개한다.
- 적 방어선 파괴 시 남은 출현 예약을 취소하고 기존 웨이브 승리 처리를 시작한다.
- 아군 방어선 파괴 시 남은 출현 예약을 취소하고 기존 웨이브 실패 처리를 시작한다.
- 적 전멸만으로 웨이브를 종료하지 않는다.
- 핀볼 기본 보상, 콤보와 잭팟은 공세 단계와 관계없이 유지한다.
- 재도전과 다음 웨이브 시작 시 공세 경과 시간을 0으로 초기화한다.

## 3. 웨이브 출현 데이터

각 웨이브는 기존 이름, 엘리트 여부와 보스 여부를 유지하고 다음 출현 정보를 가진다.

### 초기 공세 항목

- 적 ID
- 수량
- 웨이브 시작 후 첫 출현 시점
- 같은 항목 내 개별 출현 간격

초기 공세는 항목별 첫 출현 시점을 기준으로 실행한다. 같은 시점의 항목은 데이터 순서를 보장할 필요가 없으며, 동시 생존 상한은 모든 항목에 공통 적용한다.

### 반복 증원 조합

각 웨이브는 다음 세 조합과 반복 간격을 가진다.

- 기본 증원: 초기 시간표 종료 후부터 60초 전까지 사용
- 강화 증원: 60초부터 90초 전까지 사용
- 최후 공세: 90초 이후 사용

조합은 적 ID와 수량 목록이다. 한 번의 출현 시도에서 상한 때문에 일부만 생성되면 남은 수량을 별도 대기열에 누적하지 않는다. 다음 반복 시점에 해당 단계 조합을 다시 평가한다. 이 규칙으로 대기열 폭증과 뒤늦은 적 몰림을 막는다.

초기 시간표가 60초 이후까지 이어지는 데이터는 허용하지 않는다. 데이터 검증에서 마지막 초기 출현 시점이 60초 미만인지 확인한다.

## 4. 공세 상태 소유권과 흐름

새 공세 컨트롤러가 한 웨이브의 경과 시간, 초기 출현 예약, 현재 공세 단계와 다음 반복 시점을 소유한다. `BattleManager`는 웨이브 시작과 종료를 전달하고, 컨트롤러가 요청한 적 생성은 기존 `UnitManager` 생성 경로에 위임한다.

공세 단계는 다음 네 상태를 사용한다.

- 초기 공세
- 기본 증원
- 강화 증원
- 최후 공세

경과 시간은 Unity 게임 시간 기준으로 계산한다. 일시정지에서는 멈추며 2배속에서는 2배로 진행한다. 결과 처리 진입 즉시 공세 컨트롤러를 중지해 이후 출현과 UI 갱신을 막는다.

적 생성 실패는 웨이브 결과를 바꾸지 않는다. 실패한 개체는 다음 프레임에 무한 재시도하지 않으며, 다음 예약 또는 반복 시점에서 정상 흐름을 계속한다. 잘못된 적 ID와 유효하지 않은 시간 값은 데이터 로딩 검증에서 오류로 처리한다.

## 5. 유닛별 출격 쿨다운

구매 설정에 유닛별 쿨다운 시간을 포함한다.

- 전사 `warrior`: 4초
- 궁수 `archer`: 5초
- 마법사 `mage`: 7초
- 창병 `spearman`: 5초

규칙은 다음과 같다.

- 구매와 Spawn이 모두 성공한 뒤 해당 유닛 쿨다운을 시작한다.
- 골드 부족, 생존 아군 상한, 잘못된 유닛 ID와 Spawn 실패에서는 시작하지 않는다.
- 전술 증원권 무료 출격도 성공 시 같은 쿨다운을 적용한다.
- 쿨다운 중에는 일반 구매와 무료 출격을 모두 막는다.
- 각 유닛 쿨다운은 독립적으로 흐른다.
- 준비 단계 구매에도 적용한다.
- 웨이브 결과, 재도전과 다음 웨이브 진입으로 초기화하지 않는다.
- 새 런 시작에서만 전체 쿨다운을 초기화한다.
- Unity 게임 시간 기준으로 일시정지에서는 멈추고 2배속에서는 2배로 감소한다.

쿨다운 상태는 구매 도메인 컨트롤러가 소유한다. UI는 현재 시각을 직접 계산하지 않고 남은 시간을 조회한다.

## 6. 창병 구매 연결

기존 `AllyUnitData.json`, `AllyUnit.prefab`, 초상화와 진화 계보에 존재하는 `spearman`을 기본 구매 선택지로 추가한다. 새 캐릭터 리소스는 만들지 않는다.

- 역할: 중거리 근접 공격
- 기본 비용: 35골드
- 구매 비용 증가 배율: 기존 기본 유닛과 같은 1.4
- 출격 쿨다운: 5초
- 개별 구매 횟수와 비용 증가를 사용한다.
- 기존 생존 아군 상한 5명에 포함한다.
- 전술 증원권으로 무료 출격할 수 있다.

전사보다 긴 사거리로 전열 뒤에서 공격하고, 궁수보다 짧은 사거리와 높은 생존력으로 두 역할 사이 선택지를 제공한다. 능력치와 전투 행동은 기존 데이터를 변경하지 않는다.

## 7. 구매 UI

기존 씬 배치 구매 패널에 창병 카드를 추가하고 네 카드를 같은 흐름으로 갱신한다. 런타임 자동 생성은 사용하지 않는다.

각 카드에는 역할, 현재 비용, 현재 보유 수와 쿨다운 남은 시간을 표시한다. 쿨다운 중에는 버튼을 비활성화하고 반투명 마스크와 남은 초를 표시한다.

구매 불가 원인의 표시 우선순위는 다음과 같다.

1. 출격 쿨다운
2. 생존 아군 상한
3. 골드 부족

전술 증원권 보유 중에도 쿨다운을 우회하지 않는다. 무료 출격 가능한 카드는 비용 대신 무료 상태를 표시하되 쿨다운 마스크를 우선 표시한다.

## 8. 공세 카운트다운 UI

전투 상태에서만 상태 HUD에 초시계 형태의 공세 카운트다운을 표시한다.

- 0초 이상 60초 미만: `강화 증원까지 00:SS`
- 60초 이상 90초 미만: `최후 공세까지 00:SS`
- 90초 이상: `최후 공세 진행 중`

표시 초는 남은 시간을 올림 처리해 단계 전환 전에 0초가 오래 보이지 않게 한다. 준비, 결과 처리, 승리와 패배 상태에서는 숨긴다. 60초와 90초 도달 시 짧은 색상 강조를 재생하고, 90초 도달 시 기존 사운드 흐름을 통한 경고음을 한 번만 재생한다.

UI는 공세 컨트롤러의 경과 시간과 단계 변경 이벤트를 `BattleManager`가 중계한 값만 사용한다. 별도 타이머를 두지 않아 실제 증원과 표시가 어긋나지 않게 한다.

## 9. 기존 동작 보존

- 고정 10웨이브, 준비 단계와 수동 시작
- 양측 방어선 HP 기반 승리와 실패
- 기회 3회와 같은 웨이브 재도전
- 핀볼 자동 순환, 생산 강화, 골든볼, 콤보와 잭팟
- 전술 증원권 최대 1개와 Spawn 성공 시 소비
- 전사, 궁수와 마법사의 기존 능력치·행동
- 아군 공격력과 방어선 HP 강화
- 아이템, 상점, 결과 화면과 프로토타입 지표
- 씬 배치와 Inspector 참조 우선 원칙
- `SetActive` 기반 유닛 풀링

## 10. 테스트와 검증

EditMode 테스트는 다음을 증명한다.

- 초기 항목이 정의된 시각과 간격에 따라 출현 요청된다.
- 초기 시간표 종료 후 기본 증원이 반복된다.
- 60초에 강화 증원, 90초에 최후 공세로 한 번씩 전환한다.
- 동시 생존 적 8명에서 출현을 보류하고 빈자리 발생 후 재개한다.
- 상한 때문에 누락된 조합 수량이 대기열로 누적되지 않는다.
- 결과 처리, 승리와 실패 이후 출현 요청이 발생하지 않는다.
- 재도전과 다음 웨이브에서 경과 시간과 출현 예약이 초기화된다.
- 일시정지와 2배속에서 공세 시간과 쿨다운이 Unity 게임 시간을 따른다.
- 네 유닛의 구매 성공 후 각 쿨다운이 시작된다.
- 구매 실패에서는 골드, 구매 횟수, 증원권과 쿨다운이 변하지 않는다.
- 무료 창병 출격 성공 시 증원권이 소비되고 창병 쿨다운이 시작된다.
- 공세 카운트다운 문구와 올림 초 계산이 경계값 0초, 60초와 90초에서 맞다.

씬 테스트는 다음을 확인한다.

- 창병 구매 카드의 버튼, 텍스트, 초상화, 마스크와 쿨다운 텍스트 참조
- 기존 세 카드의 마스크와 쿨다운 텍스트 참조
- 공세 카운트다운 UI 참조
- `BattleManager`의 네 유닛 구매 설정과 공세 설정

구현 후 관련 EditMode 테스트, C# 컴파일과 허용된 Unity 검증을 실행한다. PC WebGL 성능은 동시 적 8명과 기존 아군 5명 조건에서 직접 확인한다.

## 11. 비범위

- 전선 위험도, 거리 계산과 위험 HUD
- 덱 편성
- 기지 액티브 스킬
- 새 캐릭터 아트와 애니메이션
- 창병 능력치와 진화 규칙 변경
- 가챠, 희귀도와 영구 성장
- 핀볼 골드 상한 또는 전투 경제 재설계
- 적 능력치의 시간 기반 무한 성장
- 아군 생존 상한 변경
- 외부 패키지 추가
- 요청과 무관한 리팩터링
