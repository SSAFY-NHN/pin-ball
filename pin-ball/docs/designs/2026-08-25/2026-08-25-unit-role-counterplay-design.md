# 유닛 역할 상성 강화 설계

## 1. 목적

전사, 궁수, 마법사와 창병을 반복 구매할 때 실제 전투 선택이 달라지도록 역할 상성을 강화한다. 별도 속성 태그와 추가 피해 표를 만들지 않고, 생존력, 사거리, 공격 범위, 방어 관통과 적 조합으로 자연스러운 유불리를 만든다.

시간표 기반 공세, 유닛별 출격 쿨다운과 창병 구매 구현을 선행 조건으로 사용한다. 기존 전투 상태, 양측 방어선 승패, 핀볼 경제와 전술 증원권은 유지한다.

## 2. 설계 원칙

- 적 속성 태그와 유닛별 상성 배율을 추가하지 않는다.
- 선택 이유는 실제 공격 방식과 전장 배치에서 드러나야 한다.
- 기본 유닛 역할은 진화 계열에서도 유지한다.
- 새 행동은 마법사 계열 범위 기본 공격과 창병 계열 방어 관통만 추가한다.
- 전사와 궁수는 기존 생존력, 사거리와 공격 속도를 먼저 검증한다.
- 플레이 테스트 근거 없이 여러 능력치를 동시에 조정하지 않는다.
- 기존 가장 가까운 적 우선 타겟 규칙은 변경하지 않는다.

## 3. 아군 역할

### 전사 계열

- 역할: 돌진 저지와 전열 방어
- 높은 HP와 방어력으로 늑대와 암살자의 빠른 접근을 받아낸다.
- 새 특수 공격과 강제 타겟 규칙을 추가하지 않는다.
- 기본 전사와 기사·광전사의 현재 능력치와 스킬을 유지한다.

### 궁수 계열

- 역할: 장거리 단일 지속 피해
- 긴 사거리에서 트롤과 보스 같은 고체력 목표에 꾸준히 피해를 준다.
- 후방 적 직접 우선 공격이나 관통 기본 공격을 추가하지 않는다.
- 기본 궁수와 레인저·명사수의 현재 능력치와 스킬을 유지한다.

### 마법사 계열

- 역할: 원거리 범위 피해
- 기본 공격의 주 대상에게 기존 피해 100%를 적용한다.
- 주 대상 주변 반경 1.5 안에서 가장 가까운 다른 적을 최대 2명 선택한다.
- 보조 대상에게 각각 기본 공격 피해의 60%를 적용한다.
- 주 대상은 보조 대상 목록에서 제외하고 같은 적에게 중복 피해를 주지 않는다.
- 범위 안 보조 대상이 없으면 기존 단일 공격과 같은 결과를 낸다.
- 마법사, 화염술사와 빙결술사에 동일하게 적용한다.
- 스킬 범위 피해는 이 기본 공격 특성과 별도로 기존 규칙을 유지한다.
- 방어선 기본 공격에는 보조 대상 피해를 만들지 않는다.

### 창병 계열

- 역할: 중거리 방어 관통
- 기본 공격이 대상 방어력의 40%를 무시한다.
- 방어력 0 이하 대상에서는 추가 피해를 만들지 않는다.
- 창병, 돌격창병과 방진수호병에 동일하게 적용한다.
- 스킬 피해의 기존 방어 무시 규칙은 변경하지 않는다.
- 방어선 공격에는 방어 관통을 적용하지 않는다.

## 4. 계열 판정

계열은 현재 유닛 데이터의 `id`와 `previousJob` 관계를 사용한다.

- 전사 계열: `warrior`, `knight`, `berserker`
- 궁수 계열: `archer`, `ranger`, `marksman`
- 마법사 계열: `mage`, `pyromancer`, `frost`
- 창병 계열: `spearman`, `lancer`, `guard`

새 태그 필드와 별도 상성 데이터 파일은 추가하지 않는다. 기존 데이터 로딩 시 확보되는 직업 계보를 공격 컨텍스트에 전달해 기본 공격 정책이 계열 행동을 선택한다.

## 5. 전투 계산 소유권

기본 공격 한 번의 결과 계산은 유닛별 `Update` 로직에 직접 넣지 않는다. 기존 공격 경로가 주 대상 공격을 수행한 뒤, 아군 기본 공격 특성 컨트롤러가 계열별 후속 처리를 담당한다.

- 마법사 계열: 기존 `UnitTargetFinder`로 주 대상 주변 적을 조회하고 보조 피해를 적용한다.
- 창병 계열: 주 대상 피해 계산 전에 방어 무시 비율 0.4를 제공한다.
- 전사·궁수 계열: 기존 단일 기본 공격 경로를 그대로 사용한다.

보조 피해도 기존 `TakeDamage` 경로를 통과해 방어력, 피해 표시, 사망 처리와 지표 집계를 보존한다. 기본 공격 피격당 마나 획득과 피격 반응은 실제 피해를 받은 각 대상에서 기존 규칙대로 발생한다.

## 6. 적 대응 관계

- 전사 유리: 늑대와 암살자 돌진을 받아내 후열을 보호한다.
- 마법사 유리: 고블린과 늑대 물량을 범위 기본 공격으로 처리한다.
- 창병 유리: 방패병, 오크와 오우거의 높은 방어력을 일부 무시한다.
- 궁수 유리: 트롤과 보스에게 긴 사거리에서 지속 단일 피해를 준다.

이는 강제 승패 관계가 아니다. 다른 유닛도 모든 적에게 정상 피해를 주며, 조합과 현재 골드·쿨다운에 따라 대체할 수 있다.

## 7. 10웨이브 학습 순서

기존 시간표 데이터 구조와 0초 초기 공세, 60초 강화 증원, 90초 최후 공세 경계는 유지한다. 각 웨이브의 초기·반복 조합만 역할 주제에 맞게 조정한다.

1. 고블린 물량: 마법사 범위 공격 소개
2. 늑대 돌진: 전사 전열 필요성 소개
3. 근접과 적 궁수: 전사·궁수 조합
4. 물량과 원거리: 마법사를 지키는 전열 학습
5. 방패병: 창병 방어 관통 소개
6. 방패 진형: 창병·마법사 혼합 대응
7. 오크와 트롤: 창병 관통과 궁수 지속 화력
8. 주술사와 암살자: 전사로 후열 보호
9. 정예 혼성: 네 역할 종합 시험
10. 보스와 증원: 궁수 단일 화력과 마법사 물량 처리 병행

각 웨이브의 기본·강화·최후 증원은 같은 역할 주제를 유지한다. 새 적 ID, 새 보스와 새 스킬은 추가하지 않는다. 현재 동시 생존 적 상한 8명을 넘는 조합은 사용하지 않는다.

## 8. UI와 피드백

구매 카드 역할 문구를 다음과 같이 갱신한다.

- 전사: `돌진 저지 · 전열 방어`
- 궁수: `장거리 · 단일 지속 피해`
- 마법사: `원거리 · 범위 피해`
- 창병: `중거리 · 방어 관통`

상성 아이콘, 속성표, 별도 튜토리얼 팝업과 적 머리 위 약점 표시는 추가하지 않는다. 마법사의 기존 공격 이펙트를 보조 대상 위치에도 재생해 범위 공격 원인을 보여준다. 창병은 기존 공격 이펙트를 유지하고 역할 문구로 방어 관통을 설명한다.

## 9. 기존 동작 보존

- 고정 10웨이브와 시간표 기반 공세 단계
- 동시 생존 적 상한 8명
- 유닛별 출격 쿨다운과 창병 구매
- 생존 아군 상한 5명
- 양측 방어선 HP 기반 승리·실패
- 기회 3회와 같은 웨이브 재도전
- 전술 증원권 획득·무료 구매·성공 시 소비
- 유닛 풀링, Spawn과 회수 흐름
- 진화 유닛의 기존 스킬
- 아이템과 공용 공격력 배율
- 핀볼 자동 순환, 생산 강화, 콤보와 잭팟
- 공세 카운트다운 UI

## 10. 테스트와 검증

EditMode 테스트는 다음을 증명한다.

- 마법사 계열 기본 공격이 주 대상에게 100% 피해를 준다.
- 반경 1.5 안의 다른 적 최대 2명에게 각각 60% 피해를 준다.
- 주 대상 중복과 세 번째 보조 대상 피해가 발생하지 않는다.
- 범위 밖 적과 방어선에는 보조 피해가 발생하지 않는다.
- 마법사, 화염술사와 빙결술사가 같은 계열 특성을 사용한다.
- 창병 계열 기본 공격이 유닛 대상 방어력 40%를 무시한다.
- 방어력 0 대상과 방어선에서 추가 이득이 발생하지 않는다.
- 창병, 돌격창병과 방진수호병이 같은 계열 특성을 사용한다.
- 전사와 궁수의 기본 공격 결과가 기존과 같다.
- 보조 피해가 기존 피해·사망 처리 경로를 사용한다.
- 10개 웨이브와 세 증원 단계가 정한 역할 주제와 적 상한을 만족한다.
- 기존 스킬, 타겟 탐색, 방어선 공격과 구매 동작 테스트가 회귀하지 않는다.

구현 후 관련 EditMode 테스트, C# 컴파일과 허용된 Unity 검증을 실행한다. 플레이 테스트에서는 10웨이브 동안 네 기본 유닛 각각을 최소 한 번 구매할 전술적 이유가 있는지, 한 유닛 반복 구매가 모든 웨이브에서 우세하지 않은지 확인한다.

## 11. 조정 원칙

첫 플레이 테스트에서는 다음 순서로 한 축씩 조정한다.

1. 웨이브 적 조합과 출현 수량
2. 마법사 보조 피해 비율
3. 창병 방어 무시 비율
4. 기존 기본 유닛 능력치

공격 방식과 기본 능력치를 동시에 바꾸지 않는다. 선택률 편중과 실제 실패 원인이 확인되기 전에는 전사·궁수 능력치를 변경하지 않는다.

## 12. 비범위

- 적·아군 속성 태그
- 상성 추가 피해 배율표
- 후방 적 우선 타겟과 타겟 수동 지정
- 덱 편성
- 기지 액티브 스킬
- 새 적, 새 보스와 새 캐릭터 리소스
- 진화·합성 규칙 변경
- 가챠, 희귀도와 영구 성장
- 핀볼 경제 재설계
- 외부 패키지 추가
- 요청과 무관한 리팩터링
