# 일직선 전투 및 직업 성장 시스템 설계

## 목표

전투 유닛을 하나의 수평 전선에서 이동시키고, 방어선 공방 시간을 늘리며, 준비 단계의 맵 영역을 직업별 공통 레벨 강화 UI로 활용한다. 동시에 구매 스폰 위치, 콤보 표시, 결과 화면의 핀볼 정지 상태를 바로잡는다.

## 확정 범위

1. 모든 전투 유닛은 X축으로만 이동한다.
2. 아군 구매 유닛은 아군 방어선 스폰 지점에서만 생성한다.
3. 적 유닛은 적 방어선 스폰 지점에서만 생성한다.
4. 양쪽 방어선의 기본 최대 HP를 20에서 300으로 높인다.
5. 모든 아군과 적군의 데이터상 기본 이동 속도를 50% 낮춘다.
6. 아이템 구매는 준비 단계에서만 허용하는 기존 규칙을 유지한다.
7. 콤보 UI의 겹친 텍스트 구조를 단일 텍스트와 별도 시간 게이지로 바꾼다.
8. 직업별 공통 레벨 강화와 상위 직업 구매 해금을 추가한다.
9. 최종 ResultPanel이 표시되면 모든 핀볼 물리와 자동 재생성을 정지한다.
10. 맵에 표시되는 파란 선은 아군 방어선 표시이므로 유지한다.

## 전투 이동과 스폰

전투 기준선은 아군과 적군 스폰 지점이 공유하는 중앙 Y 좌표다. 유닛은 생성될 때 해당 Y 좌표에 놓이고, 이동 목표와 넉백 결과에도 같은 Y 좌표를 유지한다. 타깃의 실제 Y 좌표, 준비 그리드, 적 편대 인덱스는 전투 이동이나 생성 위치에 영향을 주지 않는다.

아군 구매 시 `UnitPreparationController.TryPlaceInFreeGridSlot`을 통한 임의 준비 위치 배치를 사용하지 않는다. 구매된 아군은 `allySpawnPoint`에서 생성되며, 전투 중 구매되면 즉시 전투에 참여한다. 적 정규 웨이브와 증원도 `enemySpawnPoint`에서 생성한다. 소환 스킬이 전달하는 중심 좌표는 X축 배치 의도만 유지하고 Y축은 전투 기준선으로 고정한다.

이동 속도 감소는 런타임에 숨은 전역 배율을 더하지 않고 `AllyUnitData.json`과 `EnemyUnitData.json`의 `moveSpeed` 값을 절반으로 조정한다. 데이터가 실제 밸런스 값을 그대로 보여 주고 상태 효과 배율은 기존 의미를 유지한다.

## 방어선 공방

현재 방어선 최대 HP 20은 기본 유닛의 1회 공격 피해보다 낮아 도착 직후 파괴된다. 양쪽 기본 최대 HP를 300으로 올린다. 기본 유닛 한 명 기준 약 10~15초 동안 공격해야 파괴되며, 여러 유닛이 합류하면 더 빨라진다.

유닛의 기존 행동 순서는 유지한다. 살아 있는 상대 유닛이 있으면 상대 유닛을 우선 타깃으로 삼고, 상대가 없을 때만 방어선을 공격한다. 따라서 방어선을 공격하는 도중 적 증원이 생성되면 다음 Tick에서 증원을 우선 공격한다. 방어선 HP가 0이 되기 전에는 방어선 도달 자체로 웨이브를 끝내지 않는다.

기존 아군 방어선 HP 업그레이드는 300을 기준으로 계속 동작한다. 적과 아군 기본 HP는 같지만 기존 업그레이드는 아군 방어선에만 적용한다.

## 직업별 공통 레벨

새 `AllyProgressionController`가 런 단위 직업 레벨과 구매 해금 상태를 소유한다. 개별 `AllyUnit`이 아니라 직업 ID별로 레벨을 저장한다.

- 기본 직업: `warrior`, `archer`, `mage`, `spearman`
- 시작 레벨: Lv.1
- 최대 레벨: Lv.10
- 다음 레벨 비용: `ceil(150 × 1.35^(현재 레벨 - 1))` Gold
- Lv.5: 첫 번째 상위 직업 구매 해금
- Lv.10: 두 번째 상위 직업 구매 해금
- 새 게임 시작: 모든 직업 레벨과 해금 상태 초기화

해금 순서는 현재 데이터 순서를 따른다.

- 전사 Lv.5 `knight`, Lv.10 `berserker`
- 궁수 Lv.5 `ranger`, Lv.10 `marksman`
- 마법사 Lv.5 `pyromancer`, Lv.10 `frost`
- 창병 Lv.5 `lancer`, Lv.10 `guard`

기본 직업 레벨이 오르면 현재 보유 중인 같은 직업 유닛의 HP, 공격력, 방어력, 공격 속도를 새 레벨 기준으로 즉시 갱신한다. 새로 구매한 같은 직업 유닛도 공통 레벨을 적용받는다. 현재 HP는 최대 HP 변화 비율을 보존한다.

상위 직업은 별도 구매 유닛이다. 기본 직업 유닛을 교체하거나 제거하지 않는다. 이번 범위에서 상위 직업은 추가 레벨업 대상이 아니다. 구매 목록은 해금된 상위 직업만 후보로 포함한다.

구매 패널에는 기본 직업 4개와 상위 직업 8개 카드를 사전 배치한다. 잠긴 상위 직업도 해금 레벨을 보여 주되 구매 버튼은 비활성화한다. 상위 직업 기본 비용은 원본 기본 직업 비용의 2배이며 비용 배율과 쿨다운은 원본 직업 설정을 따른다.

강화는 `BattleManager.CanUsePreparationActions`가 참인 준비 단계에서만 가능하다. Gold 부족, 미보유 기본 직업, 최대 레벨, 전투 진행 중에는 구매를 거절하며 상태를 바꾸지 않는다.

## UnitUpgradePanel

`UnitUpgradePanel`은 기존 패널을 재사용하지 않고 전투 맵 영역 위에 새로 배치한다. 사용자가 열고 닫는 패널이 아니다.

- 준비 단계 진입: 자동 표시
- 전투 시작: 자동 숨김
- 최종 승리 또는 패배: 숨김
- 표시 순서: 전투 맵 위, `WaveResultPanel` 아래

전사, 궁수, 마법사, 창병 카드 4개를 항상 표시한다. 각 카드는 초상화, 직업명, 현재 레벨, 다음 레벨 능력치, 강화 비용, 강화 버튼, Lv.5/Lv.10 해금 상태를 보여 준다. 보유하지 않은 직업은 `유닛 구매 후 강화 가능`을 표시하고 버튼을 비활성화한다.

강화 성공 시 Gold, 해당 카드, 구매 가능 직업 목록, 현재 배치된 같은 직업 유닛 능력치를 같은 프레임에 갱신한다.

## 아이템 구매 상태

아이템 시스템과 카탈로그는 활성 상태다. `ShopPanel`이 준비 행동 가능 여부를 구매 버튼에 전달하므로 전투 중 버튼이 비활성화되는 것이 현재 설계다. 이 규칙을 유지한다. 준비 단계에서는 Gold, 구매 제한, 튜토리얼 제한을 만족하면 구매할 수 있다.

## 콤보 표시

현재 `PinballComboDisplay`는 동일 문구를 배경 TMP와 전경 TMP에 동시에 쓰고 전경을 마스크로 잘라 진행도를 표현한다. 두 텍스트의 레이아웃 또는 글꼴 메시에 차이가 생기면 글자가 어긋난다.

표시 문구는 단일 TMP로 렌더링한다. 남은 콤보 시간은 텍스트를 자르지 않고 별도 Filled Image 게이지의 `fillAmount`로 표시한다. 기존 펀치 애니메이션, 콤보 수, 보상 배율 표기는 유지한다.

## ResultPanel과 핀볼 정지

최종 `ResultPanel`이 승리 또는 패배로 표시될 때 `PinballManager`에 종료 정지를 요청한다. 활성 핀볼과 재생성 대기 핀볼 모두 선형 속도와 각속도를 0으로 만들고 `Rigidbody2D.simulated`를 끈다. 자동 재생성 큐는 더 이상 처리하지 않으며 콤보 시간도 갱신하지 않는다.

`Time.timeScale`은 변경하지 않는다. 결과 화면의 재시작과 타이틀 버튼, 비스케일 UI 애니메이션은 계속 동작해야 한다. 새 게임 씬에서는 기존 초기화 흐름이 핀볼을 정상 상태로 만든다.

## 파란 선

씬의 파란 세로선은 `AllyDefenseLine`의 SpriteRenderer다. 방어선 충돌 판정, 피격 연출, HP 표시가 연결된 전투 요소이므로 제거하지 않는다. 튜토리얼의 `FocusFrame`에도 청록색 Image가 있지만 부모 `TutorialFocusIndicator`가 비활성 상태여서 평상시 파란 선의 원인이 아니다.

## 테스트와 검증

Editor 테스트로 다음 동작을 고정한다.

- 이동 결과의 Y 좌표가 시작 전투선과 같음
- 아군과 적군 스폰에 랜덤 Y 오프셋이 없음
- 방어선 HP 300과 누적 피해 처리
- 상대 유닛 생성 시 방어선보다 유닛을 우선 타깃으로 선택
- 직업별 레벨 비용, 최대 레벨, Lv.5/Lv.10 해금
- 준비 단계 밖 강화 거절과 Gold 보존
- 레벨 상승 후 기존 유닛과 신규 유닛에 같은 능력치 적용
- 잠긴 상위 직업 구매 거절과 해금 후 허용
- ResultPanel 종료 상태에서 모든 핀볼 물리 정지
- UnitUpgradePanel과 콤보 UI의 필수 씬 참조

Unity EditMode 전체 테스트와 WebGL 빌드를 실행한다. 수동 확인에서는 한 줄 이동, 방어선 공격 시간, 증원 우선 타깃, 준비 단계 패널 전환, 상위 직업 구매 목록, 콤보 정렬, 결과 화면 핀볼 정지를 확인한다.

## 범위 밖

- 상위 직업 자체 레벨업
- 런 사이 레벨 또는 해금 영구 저장
- 아이템 구매 가능 단계 변경
- 기존 전체 아군 공격력 및 아군 방어선 HP 업그레이드 제거
- 방어선 시각 요소 제거
