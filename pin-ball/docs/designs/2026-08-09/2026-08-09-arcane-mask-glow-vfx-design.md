# 아케인 핀볼 마스크 발광 및 VFX 설계

## 목표

현재 GAME 씬의 수동 배치와 물리 Collider를 유지하면서, 분리 제작된 마스크와 VFX PNG를 이용해 중간 강도의 아케인 발광 피드백을 제공한다. 평상시 발광은 장치 형태를 읽을 수 있을 정도로 제한하고, 충돌·작동·골인 순간에만 강한 펄스를 사용한다.

## 렌더링 방식

- 원본 SpriteRenderer는 기존 비발광 스프라이트를 그대로 표시한다.
- 각 대상에는 마스크 전용 SpriteRenderer를 자식으로 한 개 추가한다.
- 발광 셰이더는 마스크 텍스처의 명도와 알파를 곱해 발광 영역을 결정한다.
- 마스크 레이어는 원본 SpriteRenderer의 bounds, flip, sorting layer, sorting order에 맞춘다.
- 평상시 강도는 중간 이하로 유지하고, 작동 시 짧은 펄스로 강도를 높인다.
- 마스크 PNG는 원본 색을 대체하지 않으며 흰색 불투명 덩어리로 렌더링되지 않아야 한다.

## 대상별 효과

### 공

- `ball_arcane_mask.png`로 상시 발광한다.
- `vfx_ball_trail.png`를 이동 궤적에 사용한다.
- 충돌 시 `vfx_ball_impact.png`와 `vfx_ball_ring.png`를 동시에 짧게 재생한다.

### 범퍼

- 일반 범퍼는 `bumper_standard_mask.png`, 특수 범퍼는 `bumper_special_mask.png`를 사용한다.
- 공 충돌 시 발광 강도를 짧게 올렸다가 기본값으로 복귀한다.
- 기존 반발 물리와 아이템 적중 집계는 유지한다.

### 자석

- `magnet_device_mask.png`로 기본 발광한다.
- 마우스 작동 시간 동안 `vfx_magnet_arc.png`와 `vfx_magnet_spark.png`를 표시한다.
- 기존 흡인력, 지속시간, 재사용 대기시간은 변경하지 않는다.

### 반사핀

- `reflector_auto_mask.png`를 사용한다.
- 자동 회전 시작 시 짧은 발광 펄스를 재생한다.
- 기존 감지 범위, 회전, 반발 동작은 유지한다.

### 골 룬

- 직업별 룬 마스크를 해당 룬 스프라이트와 연결한다.
- 공이 골에 들어가면 사방 아크 VFX와 `vfx_goal_spark.png`를 재생한 뒤 공 처리 로직을 실행한다.
- 골 판정 Collider와 유닛 생성 데이터는 변경하지 않는다.

## 구조

- 공 전용 효과는 기존 `PinballArcaneVfx`를 확장한다.
- 장치 공통 마스크 정렬과 펄스는 작은 공용 Controller가 담당한다.
- 범퍼, 자석, 반사핀, 골은 기존 Controller에서 공용 발광 Controller를 호출한다.
- 런타임 효과 오브젝트는 최초 한 번 생성한 뒤 `SetActive` 또는 재사용 방식으로 관리한다.
- GAME 씬의 장치 Transform, Collider, 수동 배치는 수정하지 않는다.

## 실패 처리

- 마스크나 VFX Sprite를 찾지 못한 경우 해당 효과만 비활성화하고 게임 진행은 유지한다.
- Shader를 찾지 못하면 한 번 경고를 남기고 원본 SpriteRenderer만 사용한다.
- 효과 누락 때문에 범퍼, 자석, 반사핀, 골 판정이 중단되어서는 안 된다.

## 검증 기준

- 평상시 원본 장치 형태가 보이고 흰색 덩어리가 생기지 않는다.
- 공, 범퍼, 자석, 반사핀, 룬의 발광 위치가 원본과 겹친다.
- 공 이동과 충돌, 자석 작동, 반사핀 회전, 골인에 각 전용 VFX가 재생된다.
- 여러 차례 공을 발사해도 효과 오브젝트가 계속 증가하지 않는다.
- 기존 수동 배치와 물리 기능이 유지된다.
