# 고정 웨이브·양측 방어선 전투 복구 설계

## 1. 목적

현재 `temp` 브랜치의 무한 연속 스테이지를 제거하고 `Dev` 브랜치의 고정 10웨이브, 준비 단계, 수동 웨이브 시작, 웨이브 결과 처리, 웨이브 HUD, 승리·패배 결과 화면을 복구한다.

웨이브 승패는 유닛 전멸이 아니라 양측 방어선 파괴로 판정한다. 아군 방어선이 파괴되면 남은 기회를 소비하고 같은 웨이브를 재시도하며, 적 방어선이 파괴되면 다음 웨이브로 진행한다.

## 2. 확정 규칙

- 전투는 `BattleWaveData.json`에 정의된 10개 웨이브로 진행한다.
- 각 웨이브는 준비 단계에서 사용자가 시작한다.
- 웨이브 시작 시 아군·적군 방어선 HP를 최대치로 초기화한다.
- 양측 방어선 기본 최대 HP는 각각 20이다.
- 유닛은 공격 가능한 상대 유닛이 없으면 상대 방어선으로 이동하고 방어선을 공격한다.
- 유닛 전멸만으로 웨이브를 종료하지 않는다.
- 적 방어선 파괴 시 현재 웨이브를 클리어한다.
- 1~9웨이브 클리어 후 다음 웨이브 준비 단계로 이동한다.
- 10웨이브 클리어 후 최종 승리한다.
- 아군 방어선 파괴 시 남은 기회를 1 감소시킨다.
- 기본 기회는 3이다.
- 기회가 남으면 같은 웨이브의 준비 단계로 돌아가 재시도한다.
- 기회가 0이면 최종 패배한다.
- 재시도와 다음 웨이브 시작 시 양측 방어선 HP를 최대치로 복구한다.
- 웨이브 클리어, 재시도, 최종 클리어 골드 보상은 지급하지 않는다.
- 기존 방어선 체력 업그레이드는 아군 방어선 최대 HP만 레벨당 10 증가시킨다.
- 전투 중 일반 아군 구매와 전술 증원을 사용할 수 있다.
- 전술 증원은 콤보 또는 잭팟으로 무료 구매권 1장을 얻고, 다음 아군 생성 성공 시 소비하는 현재 동작을 유지한다.

## 3. 유지 범위

다음 `temp` 기능은 이번 작업에서 유지한다.

- 핀볼 자동 순환
- 핀볼 생산 업그레이드
- 골든볼, 콤보 배율, 잭팟
- 아군 직접 구매와 전투 중 즉시 투입
- 전술 증원
- 아군 공격력·방어선 HP 전투 업그레이드
- 프로토타입 지표 패널
- 게임 재시작 버튼
- 현재 적 능력치 계산과 밸런스 값

수동 핀볼 발사, 골 포켓 아군 생성, 준비·전투 화면 슬라이드 등 이번 요청에 포함되지 않은 과거 기능은 복구하지 않는다.

## 4. 런 상태와 웨이브 상태

`BattleRunState`는 다음 정보를 소유한다.

- 전체 웨이브 목록
- 현재 웨이브 인덱스
- 남은 기회와 최대 기회
- 현재 `EWaveState`

`EWaveState`는 `Pending`, `Active`, `Resolving`, `Victory`, `Defeat`를 사용한다.

기존 `PlayerHp`와 `MaximumPlayerHp` 공개 접근자는 호환성을 위해 당장 제거하지 않고 남은 기회와 최대 기회를 반환하도록 유지한다. 내부 코드와 새 UI 문구에서는 HP가 아닌 기회라는 의미를 사용한다. 공개 API 정리는 별도 작업으로 남긴다.

`WaveResolutionState`를 복구해 웨이브 결과와 결과 표시 종료 시간을 관리한다. 결과 처리 중에는 중복 방어선 파괴나 중복 상태 전환을 허용하지 않는다.

## 5. 방어선 상태

새 `BattleDefenseLineController`가 양측 방어선 상태를 소유한다.

- 아군 최대 HP와 현재 HP
- 적군 최대 HP와 현재 HP
- 웨이브 시작 시 양측 HP 초기화
- 팀별 피해 적용
- 팀별 파괴 여부
- 아군 최대 HP 업그레이드 적용

`BattleManager`는 방어선 피해 요청을 검증하고 `BattleDefenseLineController`에 위임한다. 피해를 입은 팀, 현재 HP, 최대 HP를 UI에 알리는 이벤트를 발행한다.

씬에는 아군 방어선과 적군 방어선을 각각 사전 배치한다. 각 방어선은 소유 팀과 진입 방향을 식별하는 `DefenseLineTrigger`를 가진다. 런타임 자동 생성은 사용하지 않는다.

## 6. 유닛 전투 흐름

`UnitManager`는 양측 방어선 Transform 참조를 Inspector에서 받으며, 공격자의 팀을 기준으로 상대 방어선 위치를 제공한다.

`AllyUnit`과 `EnemyUnit`은 동일한 우선순위를 사용한다.

1. 살아 있는 상대 유닛을 유지하거나 새로 찾는다.
2. 상대 유닛이 있으면 기존 이동·공격 로직을 사용한다.
3. 상대 유닛이 없으면 상대 방어선으로 이동한다.
4. 상대 방어선 Trigger에 도달하면 기본 공격 주기에 맞춰 방어선을 공격한다.
5. 방어선 공격 중 상대 유닛이 새로 투입되면 방어선 공격을 중단하고 상대 유닛을 다시 우선한다.

따라서 아군이 전멸해도 적은 아군 방어선을 공격하며, 플레이어가 전투 중 아군을 구매하면 새 아군이 적의 주의를 다시 끌 수 있다. 적이 전멸해도 살아 있는 아군이 적 방어선으로 진격해 웨이브를 끝낸다.

## 7. 웨이브 시작과 결과 처리

### 준비 단계

- `BattleManager.TryStartWave`가 현재 웨이브 데이터와 아군 보유 조건을 검증한다.
- 양측 방어선 HP를 초기화한다.
- 현재 `BattleWaveData.Enemies` 구성대로 적을 생성한다.
- 상태를 `Active`로 변경한다.

### 적 방어선 파괴

- 결과를 `Cleared`로 기록한다.
- 결과 표시 시간 동안 상태를 `Resolving`으로 둔다.
- 적을 회수하고 생존 아군을 준비 위치로 복구한다.
- 마지막 웨이브면 `Victory`로 이동한다.
- 마지막 웨이브가 아니면 웨이브 인덱스를 증가시키고 `Pending`으로 이동한다.
- 골드는 지급하지 않는다.

### 아군 방어선 파괴

- 결과를 `Failed`로 기록하고 기회를 1 감소시킨다.
- 결과 표시 시간 동안 상태를 `Resolving`으로 둔다.
- 적을 회수하고 생존 아군을 준비 위치로 복구한다.
- 기회가 남으면 웨이브 인덱스를 유지하고 `Pending`으로 이동한다.
- 기회가 없으면 `Defeat`로 이동한다.
- 골드는 지급하지 않는다.

## 8. 데이터 변경

`BattleWaveData`와 `BattleWaveData.json`에서 다음 필드를 제거한다.

- `RetryGoldReward`
- `WaveClearGoldReward`
- `FinalClearGoldReward`

`TitleData`의 해당 보상 유효성 검사도 제거한다. 적 구성, 엘리트 여부, 보스 여부와 기존 웨이브 이름은 유지한다.

무한 스테이지 전용 설정은 `BattleManager`와 게임 씬에서 제거한다.

- 단계 전환 시간 기반 자동 다음 단계 예약
- 단일 일반 적 ID
- 적 수 증가 간격·증가량·최대 수
- 반복 보스 ID·간격·배율

고정 10웨이브의 10번째 웨이브에 정의된 `goblin_king` 구성을 사용한다.

## 9. UI 복구와 유지

- `WavePanel`의 수동 웨이브 시작 버튼과 상태 갱신을 복구한다.
- 수동 핀볼 발사 버튼과 발사 비용 UI는 복구하지 않는다.
- `StatusWaveHudController`와 10개 웨이브 노드·9개 커넥터 표시를 복구한다.
- `StatusPanel`은 남은 기회와 양측 방어선 HP를 표시한다.
- `WaveResultPanel`은 클리어와 실패 결과를 모두 표시한다.
- `ResultPanel`은 승리·패배 아트와 문구를 복구한다.
- 현재 재시작 버튼과 타이틀 이동 버튼은 모두 유지한다.
- 아군 구매 카드와 전술 증원 안내는 유지한다.
- 프로토타입 지표는 무한 단계 이벤트 대신 고정 웨이브 시작·결과 이벤트를 사용한다.

## 10. 제거 대상

다음 무한 스테이지 전용 코드와 테스트를 제거한다.

- `BattleStageController`
- `BattleStageControllerTests`
- `EnemyStageScalingController`
- `BattleManager`의 자동 다음 단계 예약과 반복 보스 판정
- 게임 씬의 무한 단계 직렬화 설정

삭제 때문에 사용되지 않게 된 이벤트, 구조체, 필드만 함께 정리한다. 다른 `temp` 기능의 코드 정리는 이번 작업에 포함하지 않는다.

## 11. 테스트와 검증

EditMode 테스트는 다음 동작을 증명한다.

- 런이 10개 웨이브와 기회 3으로 시작한다.
- 적 방어선 파괴 시 다음 웨이브로 이동한다.
- 10웨이브의 적 방어선 파괴 시 승리한다.
- 아군 방어선 파괴 시 기회가 1 감소하고 같은 웨이브를 재시도한다.
- 마지막 기회 소진 시 패배한다.
- 재시도와 새 웨이브 시작 시 양측 방어선 HP가 초기화된다.
- 유닛 전멸만으로 웨이브 결과가 발생하지 않는다.
- 상대 유닛이 없을 때 양측 유닛이 상대 방어선을 향한다.
- 전투 중 새 상대 유닛이 투입되면 방어선 공격에서 유닛 공격으로 복귀한다.
- 방어선 HP 업그레이드는 아군 방어선에만 적용된다.
- 클리어·실패·최종 승리에서 골드 보상이 발생하지 않는다.
- 전술 증원 획득·무료 구매·성공 시 소비 동작은 유지된다.

씬 테스트는 다음 참조를 확인한다.

- 양측 방어선과 Trigger
- 수동 웨이브 시작 버튼
- 10개 웨이브 HUD 노드와 9개 커넥터
- 승리·패배 결과 아트
- 재시작·타이틀 버튼
- 아군 구매 카드와 전술 증원 안내

구현 후 관련 EditMode 테스트와 허용된 Unity 검증을 실행한다. 검증 실패가 이번 변경 범위 밖이면 원인을 기록하고 관련 없는 코드는 수정하지 않는다.
