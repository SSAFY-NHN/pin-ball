# 전투 상태 기반 카메라 슬라이드 설계

## 목표

준비 상태에는 전투 맵 오른쪽에 배치된 핀볼 보드가 보이도록 카메라를 이동한다. 전투가 시작되면 카메라를 기존 전투 화면 위치로 되돌려 핀볼 보드가 보이지 않게 한다.

## 상태별 동작

- `EWaveState.Pending`: 핀볼 화면 위치로 이동한다.
- `EWaveState.Active`: 기존 전투 화면 위치로 이동한다.
- `EWaveState.Victory`, `EWaveState.Defeat`: 전투 화면 위치를 유지한다.
- 최초 초기화 시에는 애니메이션 없이 현재 상태에 맞는 위치를 즉시 적용한다.

## 구조

Main Camera에 `BattleCameraController`를 씬 배치한다. 이 컴포넌트는 `BattleManager.OnStateChanged`를 구독하고 상태에 대응하는 목표 위치로 카메라를 이동한다.

카메라의 전투 위치와 핀볼 위치는 `[SerializeField]` 필드로 노출해 Inspector에서 지정한다. 전투 위치 기본값은 현재 Main Camera 위치인 `(0, 0, -10)`을 유지하고, 핀볼 위치는 실제 보드 구도를 보며 씬에서 설정한다. 이동 시간도 Inspector에서 조절하며 초기값은 `0.5초`로 한다.

`FixedAspectCamera`는 화면 비율만 담당하며 수정하지 않는다. UI 컨트롤러에도 카메라 책임을 추가하지 않는다.

## 이동 처리

코루틴에서 현재 위치부터 목표 위치까지 보간한다. 시간 흐름은 `Time.unscaledDeltaTime`을 사용하고, 기존 UI 슬라이드와 일관된 ease-out 곡선을 적용한다.

상태가 이동 도중 바뀌면 실행 중인 코루틴을 중단하고 현재 카메라 위치에서 새 목표 위치로 다시 이동한다. 컴포넌트 파괴 시 이벤트 구독을 해제한다.

## 오류 처리

`BattleManager`를 가져오지 못하거나 필수 참조가 없으면 명확한 오류를 기록하고 카메라 이동을 시작하지 않는다. 오류를 숨기기 위한 런타임 컴포넌트 자동 생성은 사용하지 않는다.

## 검증 기준

- 게임 시작 후 준비 상태에서 핀볼 보드가 화면에 보인다.
- 전투 시작 시 카메라가 약 `0.5초` 동안 전투 위치로 부드럽게 이동한다.
- 다음 웨이브 준비 상태가 되면 카메라가 핀볼 위치로 다시 이동한다.
- 이동 도중 상태가 바뀌어도 튀거나 잘못된 위치에 멈추지 않는다.
- 승리와 패배 화면에서는 전투 화면 위치가 유지된다.
- 기존 16:9 고정 화면 비율과 전투/UI 입력이 정상 동작한다.
