# Ally Deployment Limit Design

## Goal

배치한 아군 수를 최대 권장치 5마리로 표시하고, 초과 수에 따라 웨이브 시작과 핀볼 발사를 단계적으로 제한한다.

## Confirmed Rules

- 배치 수는 `UnitManager.OwnedAllies.Count`를 기준으로 한다.
- Status UI는 `현재 수/5` 형식으로 표시한다.
- 0마리이면 기존 규칙대로 웨이브를 시작할 수 없다.
- 1~5마리이면 웨이브 시작과 핀볼 발사가 가능하다.
- 정확히 6마리이면 웨이브 시작은 불가능하지만 핀볼 발사는 가능하다.
- 7마리 이상이면 웨이브 시작과 핀볼 발사가 모두 불가능하다.
- Status UI의 수량 텍스트는 0~5마리일 때 기존 기본색, 6마리 이상일 때 빨간색을 사용한다.

## Architecture

`UnitManager`가 배치 아군 수와 두 제한 규칙의 단일 기준점이 된다. 아군 추가, 해제, 합성 등으로 보유 수가 바뀌면 변경 이벤트를 발행한다. `BattleManager`와 `PinballManager`는 실제 동작 진입점에서 제한을 검증하고, `WavePanel`과 `StatusPanel`은 같은 상태와 이벤트를 사용해 버튼 및 텍스트를 즉시 갱신한다.

이 구조는 UI 버튼만 비활성화하는 방식과 달리 다른 호출 경로에서도 규칙을 우회할 수 없으며, 숫자 기준이 여러 파일에 흩어지는 것을 막는다.

## Component Changes

### UnitManager

- 최대 권장 배치 수 5를 정의한다.
- 현재 배치 수를 공개한다.
- 웨이브 시작 가능 수량(`1..5`)과 핀볼 사용 가능 수량(`0..6`)을 공개한다.
- 보유 아군 수가 실제로 변경될 때 수량 변경 이벤트를 발행한다.
- 생성, 제거, 합성 결과 생성 경로가 기존 목록 관리를 그대로 사용하도록 유지한다.

### BattleManager

- `TryStartWave`에서 기존 준비 상태, 웨이브 데이터, 최소 1마리 검증을 유지한다.
- 아군이 6마리 이상이면 시작을 거부하고 기존 `OnActionRejected` 흐름으로 안내한다.

### PinballManager

- `TryLaunchLoadedBall`에서 기존 준비 상태, 공 존재 여부, 골드 검증을 유지한다.
- 아군이 7마리 이상이면 발사를 거부한다.
- UI가 아닌 코드나 입력 경로에서 호출해도 동일한 제한이 적용된다.

### WavePanel

- 아군 수 변경 이벤트를 구독해 버튼 상태를 즉시 갱신한다.
- 시작 버튼은 기존 조건과 함께 배치 수가 1~5일 때만 활성화한다.
- 핀볼 버튼은 기존 조건과 함께 배치 수가 6 이하일 때만 활성화한다.
- 기존 피드백 텍스트 흐름을 보존한다.

### StatusPanel

- 씬에 배치된 TMP 텍스트를 Inspector 참조로 받는다.
- 초기화 시 현재 수를 표시하고 아군 수 변경 이벤트를 구독한다.
- `현재 수/5`로 표시하며 6마리 이상일 때 초과색을 사용한다.
- 기본색과 초과색은 직렬화 필드로 받아 현재 UI 디자인 값을 보존한다.

### Scene and Prefab

- 기존 Status UI 계층 안의 TMP 텍스트를 사용하거나, 해당 요소가 없다면 같은 계층에 하나를 씬 배치한다.
- `StatusPanel`의 새 참조를 Inspector에서 연결한다.
- 런타임 UI 자동 생성은 사용하지 않는다.

## Data Flow

1. 아군이 생성, 제거 또는 합성되어 `OwnedAllies` 수가 바뀐다.
2. `UnitManager`가 새 수량으로 이벤트를 발행한다.
3. `StatusPanel`이 텍스트와 색상을 갱신한다.
4. `WavePanel`이 웨이브 및 핀볼 버튼의 `interactable`을 갱신한다.
5. 버튼이나 다른 경로가 실제 동작을 요청하면 각 Manager가 동일한 수량 제한을 다시 검증한다.

## Error and Edge Handling

- `UnitManager` 참조가 준비되지 않은 경우 기존 안전 동작을 유지하고 실행을 허용하지 않는다.
- 합성 중 두 입력 유닛 제거와 결과 유닛 생성이 같은 프레임에 일어나더라도 최종 이벤트는 올바른 최종 수량을 반영한다.
- 전투 중 사망한 아군은 `OwnedAllies`에 남으므로 표시 수는 생존 수가 아닌 배치/보유 수를 유지한다.
- 7마리 이상 상태에서 핀볼 발사 거부 시 골드는 차감하지 않는다.

## Verification

- 규칙 계산 테스트에서 5마리, 6마리, 7마리 경계를 검증한다.
- Unity Play Mode에서 `5/5`가 기본색인지 확인한다.
- 6마리에서 `6/5`가 빨간색이고 웨이브 버튼만 비활성화되는지 확인한다.
- 7마리에서 `7/5`가 빨간색이고 두 버튼 모두 비활성화되는지 확인한다.
- 제한된 상태에서 Manager 메서드를 직접 호출해도 웨이브 시작, 공 발사, 골드 차감이 발생하지 않는지 확인한다.
- 합성으로 수가 제한 이하가 되면 텍스트와 버튼이 즉시 복구되는지 확인한다.

## Scope

- 새 외부 패키지, 새 최상위 폴더, 공개 데이터 저장 형식 변경은 없다.
- 관련 없는 전투, 핀볼, UI 구조는 리팩터링하지 않는다.
- 실제 게임 코드와 씬 수정은 별도 구현 계획 승인 후 진행한다.
