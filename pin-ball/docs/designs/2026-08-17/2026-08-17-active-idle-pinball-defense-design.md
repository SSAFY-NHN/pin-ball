# 능동형 방치 핀볼 디펜스 게임 흐름 개편 기획

## 문서 목적

현재 게임의 `핀볼 준비 → 별도 자동전투` 구조를 폐기하고, 핀볼 경제와 자동전투가
한 화면에서 계속 진행되는 능동형 방치 게임으로 개편한다. 이 문서는 전체 방향과
첫 프로토타입의 범위를 정의한다. 구체적인 코드 구조와 파일별 작업 순서는 별도의
구현 계획에서 다룬다.

## 배경과 해결할 문제

현재 플레이 관찰에서는 전체 플레이 시간의 대부분이 전투 준비를 위한 핀볼에
집중되고, 전투는 웨이브 성공 여부를 확인하는 짧은 결과 구간으로 받아들여졌다.
두 콘텐츠가 순차적으로 분리되어 있어 한쪽을 플레이하는 동안 다른 한쪽의 재미가
멈추는 것이 핵심 문제다.

개편 방향은 다음 원칙을 따른다.

- 핀볼과 전투는 준비·실행 단계로 나뉘지 않고 항상 동시에 진행한다.
- 플레이어가 조작하지 않아도 생산과 전투가 계속되지만, 주기적인 구매·배치·강화가
  효율과 진행 속도를 크게 높인다.
- 오프라인 진행과 오프라인 보상은 제공하지 않는다.
- 도박성과 강한 보상 기대는 핀볼 경제에 집중한다.
- 전투는 핀볼에서 생산된 재화를 소비하고 성장 필요성을 만드는 압력으로 작동한다.
- 복잡한 수작업 웨이브 기획보다 조절 가능한 성장 공식과 구간별 보스를 사용한다.

## 게임 정체성

> 자동으로 돌아가는 핀볼 경제를 성장시켜 끊임없이 밀려오는 적을 막는
> 능동형 방치 디펜스

플레이어는 공을 직접 발사하는 조작자가 아니라 핀볼 생산 설비와 방어선을 운영하는
관리자다. 평소에는 공과 유닛이 자동으로 움직이는 모습을 관찰하고, 적절한 시점에
생산과 전투 중 어느 쪽에 투자할지 결정한다.

## 목표 플레이 감정

1. **관찰의 편안함:** 조작하지 않아도 공과 유닛이 계속 움직이며 작은 성과를 만든다.
2. **투자의 고민:** 현재 방어를 강화할지 미래 생산량을 늘릴지 선택한다.
3. **대박의 기대:** 황금 공, 콤보와 잭팟이 겹치며 평소보다 큰 수익이 발생한다.
4. **성장의 가시성:** 초반의 공 한 개와 소수 유닛이 다중 공과 강한 부대로 변한다.
5. **전선의 긴장감:** 생산과 병력 투자가 늦으면 방어선이 공격받고 런이 종료된다.

## 코어 루프

```text
공 자동 생성
→ 범퍼 충돌로 골드 생산
→ 골드를 생산 강화 또는 전투 강화에 투자
→ 아군이 계속 등장하는 적과 자동전투
→ 현재 적 그룹이 모두 사망하면 다음 웨이브 자동 예약
→ 더 높은 생산력과 전투력을 요구
→ 일정 단계마다 보스와 신규 성장 요소 해금
```

### 짧은 관찰 루프: 수초

- 공이 상단 생성 지점에서 자동으로 떨어진다.
- 범퍼 충돌마다 골드와 시각·청각 피드백이 발생한다.
- 공이 하단 종료 지점에 도달하면 풀로 돌아간다.
- 재생성 대기시간이 끝나면 같은 공이 다시 상단에서 생성된다.
- 전장에서는 아군과 적이 자동으로 이동하고 공격한다.

### 능동 개입 루프: 약 10~30초

- 모인 골드로 생산 또는 전투 업그레이드를 구매한다.
- 위험한 전선에 유닛을 추가하거나 기존 유닛을 강화한다.
- 생산 효율이 부족하면 공, 범퍼 보상 또는 생성 속도에 투자한다.
- 잭팟으로 큰 수익이 발생하면 막힌 전선을 단숨에 강화한다.

### 장기 성장 루프: 수분 이상

- 연속되는 전투 단계를 돌파한다.
- 일정 단계마다 보스를 처치한다.
- 새로운 공, 범퍼 효과, 유닛 또는 업그레이드 항목을 해금한다.
- 더 복잡하고 강한 자동화 상태를 구축한다.

## 화면과 동시 진행 원칙

- 핀볼 보드와 전장은 같은 화면에서 항상 확인할 수 있어야 한다.
- 준비 화면, 전투 시작 버튼과 웨이브 결과 대기 화면은 제거 대상이다.
- 전투 상태에 따른 카메라 이동을 사용하지 않고 두 영역이 함께 보이는 고정 구도를
  유지한다.
- UI는 현재 골드, 초당 예상 수익, 전선 위험도, 현재 단계와 보스 진행을 최소한으로
  표시한다.
- 핀볼 대박이 발생하면 골드 증가와 전투 측 구매 가능 상태가 즉시 연결되어 보인다.

### 입력과 구형 튜토리얼

- 핀볼 공은 자동 순환만 사용하며 수동 발사, 플런저 조작, 발사 버튼과 발사 비용을
  사용하지 않는다.
- 수동 발사, Goal 유닛 생성과 웨이브 시작 버튼을 요구하는 기존 튜토리얼은 새 코어
  루프와 호환되지 않으므로 첫 프로토타입에서 비활성화한다.
- 구형 튜토리얼 UI와 입력 차단은 저장된 완료 상태와 관계없이 게임 시작을 막지
  않아야 한다.
- 새 코어 루프를 설명하는 튜토리얼 재설계는 별도 후속 작업으로 둔다.

## 핀볼 생산 시스템

### 공의 자동 순환

- 공은 플레이어 입력 없이 지정된 상단 지점에서 생성된다.
- 공이 목표 또는 하단 종료 영역에 들어가면 비활성화된다.
- 각 공은 자신의 재생성 대기시간이 끝난 후 다시 생성된다.
- 공 개수 증가는 동시에 순환하는 공 슬롯의 증가를 의미한다.
- 기존 `SetActive` 기반 풀링을 유지하고 반복적인 Instantiate/Destroy를 사용하지 않는다.
- 물리와 가독성을 위해 동시 활성 공에는 상한을 둔다. 첫 프로토타입의 상한은 10개다.

### 기본 생산

- 일반 범퍼 충돌 시 `충돌 기본 골드`를 즉시 획득한다.
- 벽, 레일과 종료 영역은 기본 골드를 생성하지 않는다.
- 공 한 개의 평균 수익은 `평균 충돌 횟수 × 충돌 기본 골드`로 관찰한다.
- 공의 비정상 정지나 이탈은 대박과 별개인 안전 규칙으로 회수한다.

### 생산 업그레이드

첫 프로토타입에는 다음 세 항목만 사용한다.

1. **범퍼 수익:** 범퍼 충돌당 기본 골드 증가
2. **공 추가:** 동시에 순환하는 공 슬롯 1개 증가
3. **공급 속도:** 공 재생성 대기시간 감소

업그레이드 비용은 다음 공식을 기본으로 한다.

```text
다음 비용 = 기본 비용 × 비용 배율 ^ 현재 레벨
```

- 범퍼 수익은 선형으로 증가시켜 이해하기 쉽게 유지한다.
- 공 추가는 물리 충돌 수와 생산량을 함께 크게 바꾸므로 가장 비싼 항목으로 둔다.
- 공급 속도에는 최소 재생성 시간이 있어 0초에 도달하지 않는다.
- 구체적인 기본 비용과 비용 배율은 구현 계획에서 데이터로 분리하고 플레이 테스트로
  조절한다. 공식 자체는 첫 프로토타입 동안 변경하지 않는다.

## 도박성과 도파민 구조

도박 요소는 전투 명중이나 생존 여부가 아니라 핀볼 수익의 변동 폭에 집중한다.
운이 나쁜 구간에도 기본 생산은 계속되며, 대박은 진행을 잃지 않고 가속한다.

### 1단계: 안정적인 기본 수익

- 모든 정상 범퍼 충돌은 고정 기본 골드를 지급한다.
- 대박이 발생하지 않아도 업그레이드를 구매할 수 있다.
- 공 한 번이 아무 보상 없이 끝나더라도 누적 경제가 역행하지 않는다.

### 2단계: 콤보 배수

- 큰 범퍼가 제한 시간 안에 연속 충돌하면 공용 콤보가 오른다.
- 콤보가 높을수록 해당 충돌의 골드 배수가 증가한다.
- 제한 시간 만료 시 콤보는 초기화된다.
- 현재 구현된 큰 범퍼 콤보 UI와 비배속 시간 기준을 재사용 후보로 둔다.

### 3단계: 황금 공

- 공이 생성될 때 낮은 확률로 황금 공이 된다.
- 황금 공은 활성 시간 동안 모든 정상 범퍼 보상에 고정 배수를 적용한다.
- 황금 공 확률과 배수는 서로 다른 업그레이드로 늘리지 않고, 첫 프로토타입에서는
  고정 규칙으로 사용한다.

### 4단계: 잭팟

- 황금 공이 일정 콤보 이상에서 특수 범퍼를 맞히면 잭팟이 발생한다.
- 잭팟은 `황금 공`, `콤보`, `특수 범퍼`가 겹칠 때만 발생해 화면에서 원인을 읽을 수
  있어야 한다.
- 잭팟은 큰 골드 보상, 전용 사운드, 숫자 연출과 짧은 보드 발광으로 표현한다.
- 잭팟은 무작위 버튼 추첨이 아니라 실제 공의 움직임 끝에서 발생한다.

### 도박 시스템 안전 원칙

- 운이 나쁘다고 보유 골드나 유닛을 잃지 않는다.
- 유료 발사, 실패 시 차감과 마이너스 배율을 사용하지 않는다.
- 잭팟 없이도 정상 진행이 가능해야 한다.
- 플레이어가 계속 클릭해야 수익을 유지하는 클릭커 구조는 사용하지 않는다.

## 지속형 자동전투

### 진행 방식

- 전투 모델은 `실시간 연속 디펜스 + 데이터 기반 웨이브`다.
- 별도의 웨이브 시작 입력 없이 첫 적 그룹이 자동으로 등장한다.
- 웨이브는 등장할 적 편성, 성장 수치와 보스 여부를 결정하는 데이터 단위다.
- 웨이브는 플레이어 입력을 잠그는 준비·전투·결과 화면 단위가 아니다.
- 현재 적 그룹이 처치 또는 방어선 돌파 회수로 모두 해결되면 다음 웨이브를 한 번만
  예약하는 기존 규칙은 폐기한다.
- 현재 웨이브에 등장한 적이 모두 사망했을 때만 다음 웨이브를 한 번 예약하고
  1~2초 뒤 자동으로 등장시킨다.
- 웨이브 사이 등장 간격에는 결과 UI, 준비 UI, 입력 잠금과 카메라 이동을 사용하지
  않는다.
- 아군이 전멸해도 현재 단계는 즉시 실패하지 않으며 생존한 적은 방어선으로 계속
  이동한다.
- 플레이어는 적이 방어선으로 이동하는 동안 새 아군을 구매해 즉시 전장에 투입하고
  남은 적을 저지할 수 있다.
- 적이 방어선에 도달하면 사라지지 않고 방어선 앞에서 멈춰 일정 공격 주기마다
  방어선에 피해를 준다.
- 방어선을 공격 중인 적도 새로 투입된 아군의 정상 공격 대상이며, 플레이어는 늦게
  아군을 구매해도 방어선을 지킬 수 있다.
- 적이 없는 1~2초의 등장 간격에도 공 생성, 범퍼 수익, 업그레이드 구매와 유닛
  구매는 멈추지 않는다.
- 일정 단계마다 보스가 등장해 장기 목표와 리듬을 제공한다.

### 플레이어의 전투 투자

첫 프로토타입에는 다음 세 소비처만 사용한다.

1. **유닛 구매:** 전사, 궁수, 마법사 중 하나를 선택해 지정된 아군 슬롯에 추가
2. **아군 공격력:** 모든 아군의 공격력 배율 증가
3. **방어선 체력:** 최대 체력과 현재 체력 일부 증가

유닛 구매는 하나의 기본 유닛을 반복 구매하는 버튼이 아니라 다음 세 역할의 선택으로
구성한다.

- **전사:** 높은 체력과 방어력으로 전선을 오래 유지하는 근접 탱커
- **궁수:** 긴 사거리에서 안정적으로 단일 대상을 공격하는 원거리 지속 공격수
- **마법사:** 낮은 생존력을 감수하고 다수의 적을 공격하는 원거리 범위 공격수

- 세 유닛은 서로 다른 기본 비용을 사용하며, 같은 유닛을 반복 구매할수록 해당
  유닛의 구매 횟수를 기준으로 다음 비용이 증가한다.
- 한 유닛의 구매 횟수가 다른 유닛의 비용을 올리지 않는다.
- 전장에 보유할 수 있는 살아 있는 아군 상한은 기존 5명을 유지한다.
- 구매가 성공하면 선택한 유닛을 즉시 전장에 투입한다.
- 골드 부족, 아군 상한 도달 또는 Spawn 실패 시 골드와 구매 횟수를 변경하지 않는다.
- 각 구매 카드에는 역할, 현재 비용과 현재 보유 수를 표시한다.

첫 프로토타입에서는 직업별 개별 강화, 장비, 합성 선택지와 유닛 자동 구매를 넣지
않는다. 기존 전사, 궁수, 마법사 데이터와 자동전투를 재사용하고 선택의 차이를
확인하는 데 필요한 최소 범위만 연결한다.

### 단계 성장 공식

수작업으로 모든 단계를 작성하지 않고 다음 형태의 데이터 공식으로 시작한다.

```text
적 체력 = 기본 체력 × 체력 성장률 ^ (단계 - 1)
적 공격력 = 기본 공격력 × 공격 성장률 ^ (단계 - 1)
적 수 = 기본 적 수 + 단계 구간 보너스
```

- 체력 성장률은 공격 성장률보다 높게 시작해 즉사보다 진행 정체를 먼저 만든다.
- 적 수는 매 단계가 아니라 일정 단계 구간마다 증가시켜 화면 혼잡을 제한한다.
- 보스 단계는 일반 공식에 보스 전용 배율을 적용한다.
- 적 이동 속도와 공격 속도는 초기 프로토타입 동안 단계에 따라 증가시키지 않는다.
  여러 성장축을 동시에 바꾸면 난이도 원인을 분석하기 어렵기 때문이다.

## 방어선 공방과 런 종료

- 적에게 공격할 아군이 없으면 적은 씬에 배치된 방어선을 향해 이동한다.
- 적 개체가 방어선 도달 영역에 진입하면 이동을 멈추고 방어선을 반복 공격한다.
- 방어선 피해는 적의 별도 돌파 일회 피해가 아니라 실제 공격력과 공격 주기를
  사용한다. 구체적인 방어 적용 여부는 구현 설계에서 기존 전투 계산과 맞춘다.
- 아군 전멸 자체는 패배 조건이 아니며 단계 재시작을 발생시키지 않는다.
- 방어선을 공격 중인 적이 남아 있으면 현재 웨이브는 완료되지 않는다.
- 현재 웨이브의 모든 적이 사망했을 때만 1~2초 뒤 다음 웨이브가 자동 등장한다.
- 방어선 체력이 0이 되면 적 생성, 유닛 구매와 전투 진행을 멈추고 런을 종료한다.
- 게임 오버 결과 화면은 도달 웨이브와 런 결과를 표시하고 `다시 시작`, `타이틀`
  버튼을 제공한다.
- `다시 시작`은 새 런을 초기 상태에서 시작하며, `타이틀`은 Title 씬으로 이동한다.
- 아군은 웨이브 사이에 살아 있는 동안 유지되지만 체력이 0이 되면 보유 목록에서도
  제거되어 다시 구매해야 한다.

## 경제와 전투의 관계

핀볼과 전투는 같은 골드를 사용하며, 기본 진행은 직접적인 확률 의존 없이 유지한다.

```text
핀볼의 기본 생산 + 간헐적 대박
→ 골드 축적
→ 생산 투자: 장기 수익 증가
또는
→ 전투 투자: 현재 전선 돌파
```

핵심 선택은 `어떤 유닛을 사서 현재 적 편성을 막을지`, `범퍼를 강화해 이후 수익을
늘릴지`다. 잭팟이 발생하면 이 선택을 여러 번 연속 실행할 수 있어 진행이 순간적으로
가속된다.

### 전술 증원권

핀볼의 큰 성공이 전투 선택으로 즉시 이어지도록 한 가지 교차 효과만 사용한다.

- 큰 범퍼 공용 콤보가 지정된 기준에 처음 도달하거나 잭팟이 발생하면 `전술 증원권`
  1개를 얻는다.
- 증원권은 최대 1개만 보유하며 이미 보유 중일 때 발생한 추가 획득은 중첩하지 않는다.
- 증원권을 보유한 상태에서 전사, 궁수 또는 마법사 구매 카드를 선택하면 선택한
  유닛을 골드 소모 없이 소환한다.
- 무료 소환도 해당 유닛의 구매 성공 횟수에는 포함되어 이후 비용 증가에 반영한다.
- 증원권은 유닛 Spawn이 성공한 뒤에만 소비한다.
- 아군 상한 도달, 잘못된 유닛 데이터 또는 Spawn 실패 시 증원권을 유지한다.
- 잭팟의 기존 골드 보상은 그대로 지급한다.
- UI에는 증원권 보유 상태와 `다음 유닛 무료`를 명확히 표시한다.
- 콤보 기준값은 현재 콤보 도달 분포를 확인해 데이터로 조정하며, 한 번의 콤보
  연속 구간에서는 기준을 여러 번 넘나들어도 증원권을 한 번만 지급한다.

핀볼 충돌로 유닛이 직접 공격하거나 적 처치가 공을 복제하는 추가 교차 효과는 넣지
않는다. 전술 증원권 하나로 핀볼 성과와 전투 선택의 연결 효과를 먼저 검증한다.

## 콘텐츠 진행과 해금

첫 프로토타입은 한 개의 보드와 한 개의 전장에서 끝없이 단계를 올리는 구조다.

- 일반 단계는 공식 기반 적 그룹을 사용한다.
- 10단계마다 보스가 등장한다.
- 보스 처치 후 생산 또는 전투의 신규 항목 하나가 해금될 수 있다.
- 보드 지형을 단계마다 변경하지 않는다.
- 영구 성장, 환생, 다중 보드, 오프라인 보상은 첫 프로토타입 범위에서 제외한다.

## 첫 프로토타입 범위

### 반드시 포함

- 상단 자동 공 생성과 하단 회수
- 최대 10개의 공 슬롯과 `SetActive` 기반 순환
- 일반 범퍼 충돌 골드
- 범퍼 수익, 공 추가, 공급 속도 업그레이드
- 큰 범퍼 콤보
- 고정 확률 황금 공
- 조건이 명확한 잭팟 한 종류
- 데이터 기반 적 웨이브와 모든 적 사망 후 1~2초 뒤 다음 웨이브 자동 등장
- 일반 웨이브 완료 시 결과 UI·입력 잠금·카메라 이동 없는 연속 플레이
- 아군 전멸 후 생존 적의 방어선 이동과 플레이어의 즉시 아군 재투입
- 적의 방어선 도달 후 반복 공격과 전투 중 저지
- 전사, 궁수, 마법사 선택 구매와 유닛별 비용 증가
- 콤보 기준 도달 또는 잭팟으로 얻는 최대 1개의 전술 증원권
- 증원권을 사용한 다음 선택 유닛 무료 소환
- 공용 공격력 강화와 방어선 강화
- 방어선 파괴 시 게임 오버와 `다시 시작`, `타이틀` 결과 선택
- 10단계 보스 한 종류

### 포함하지 않음

- 오프라인 진행 또는 오프라인 보상
- 환생과 영구 메타 성장
- 공·범퍼·유닛의 희귀도 등급
- 장비, 직업별 스킬 트리와 복잡한 합성
- 전술 증원권 외 핀볼의 직접 전투 개입 효과
- 자동 구매와 자동 업그레이드
- 단계별 보드 구조 변경
- 수동 공 발사, 플런저 조작과 발사 비용
- 구형 수동 발사·Goal 소환·웨이브 시작 튜토리얼
- 유료 발사와 수익 손실 페널티
- 신규 외부 패키지와 저장 형식 변경

## 초기 밸런스 목표

초기 수치는 절대적인 정답이 아니라 프로토타입 검증을 위한 목표 범위로 사용한다.

- 첫 업그레이드 구매: 시작 후 20~40초
- 첫 추가 아군 구매: 시작 후 10~20초
- 전사, 궁수, 마법사 중 최소 두 선택지가 같은 시점에 구매 가능한 구간 제공
- 첫 공 추가 구매: 시작 후 2~4분
- 첫 보스 도달: 시작 후 8~12분
- 일반 상황의 능동 개입: 10~30초마다 한 번
- 잭팟 체감 빈도: 3~7분에 한 번
- 잭팟 보상 가치: 발생 시점 일반 수익의 약 30~90초분
- 전술 증원권 보유 상한: 1개
- 전술 증원권 체감 획득 간격: 일반 진행에서 1~3분에 한 번
- 방치 가능한 시간: 현재 전력이 충분한 단계에서는 최소 1~3분
- 기본 적이 방어선에 도달하기까지 대응 시간: 아군이 없을 때 최소 10초

## 계측과 밸런스 검증

첫 구현부터 다음 값을 런타임에서 관찰할 수 있어야 한다.

- 분당 생성 공 수
- 공당 평균 범퍼 충돌 횟수
- 분당 기본 골드와 대박 골드
- 업그레이드별 구매 시점과 레벨
- 유닛 종류별 구매 횟수, 구매 시점과 사망 시점
- 전술 증원권 획득 원인, 보유 시간, 사용 유닛과 사용 실패 원인
- 단계별 전투 시간
- 단계별 방어선 피해와 게임 오버 도달 시간
- 잭팟 발생 간격과 한 번의 획득량

성공 기준은 다음과 같다.

1. 플레이어가 손을 놓아도 생산과 전투가 오류 없이 계속된다.
2. 10~30초마다 확인할 가치가 있는 구매 또는 위험 신호가 나타난다.
3. 생산 투자와 전투 투자 중 하나가 항상 명백한 정답이 되지 않는다.
4. 잭팟 없이도 첫 보스에 도달할 수 있다.
5. 잭팟은 진행을 가속하지만 여러 단계를 자동으로 무력화하지 않는다.
6. 방어선 공격이 시작된 뒤에도 새 아군 구매로 전선을 복구할 시간이 있다.
7. 공 수가 증가한 후에도 PC WebGL에서 움직임과 보상 원인을 읽을 수 있다.
8. 적 편성과 전선 상태에 따라 전사, 궁수, 마법사 중 유리한 구매 선택이 달라진다.
9. 전술 증원권 획득 후 어떤 유닛에 사용할지 즉시 판단할 수 있다.

## 주요 위험과 대응

### 전투가 다시 배경 영상이 되는 위험

- 방어선 위험도를 명확히 표시한다.
- 전투 투자가 즉시 생존과 단계 진행에 반영되게 한다.
- 전선이 안정적일 때는 생산 투자가 자연스럽게 우세하도록 리듬을 만든다.

### 업그레이드가 단순 숫자 버튼으로만 느껴지는 위험

- 공 추가와 황금 공처럼 화면에서 즉시 보이는 성장을 우선한다.
- 첫 프로토타입 검증 후에만 특수 공과 범퍼 변형을 추가한다.

### 대박이 없을 때 지루한 위험

- 기본 충돌 피드백과 콤보를 계속 제공한다.
- 잭팟을 기다리지 않아도 꾸준히 구매할 수 있는 기본 생산량을 보장한다.

### 공 증가로 물리와 성능이 불안정해지는 위험

- 첫 프로토타입의 동시 활성 공을 10개로 제한한다.
- 풀링, 최대 속도와 비정상 정지 회수 규칙을 유지한다.
- WebGL 성능 검증 후에만 상한을 변경한다.

### 유닛 하나만 반복 구매하는 위험

- 전사, 궁수, 마법사의 역할 차이가 실제 사거리, 생존력과 다수 공격에서 드러나게
  한다.
- 유닛별 구매 횟수 기반 비용 증가로 다른 역할을 섞을 경제적 이유를 만든다.
- 모든 상황의 정답 유닛이 생기면 새 시스템을 추가하기 전에 기존 능력치와 적 편성을
  한 축씩 조정한다.

### 밸런스 축이 너무 많아지는 위험

- 첫 프로토타입의 생산 강화 3개, 전투 소비처 3개와 전술 증원권 1개를 고정한다.
- 한 번의 조정에서 하나의 성장축만 변경한다.
- 단계별 수작업 예외는 10단계 보스 외에는 만들지 않는다.

## 구현 단계 분리 원칙

다른 대화에서 구현할 때는 전체 시스템을 한 번에 완성하지 않는다.

기존 기본 시스템과 연속 방어선 흐름 구현 이후 남은 작업은 다음 순서로 진행한다.

1. 기존 단일 유닛 구매를 전사, 궁수, 마법사 선택 구매로 교체하고 유닛별 기본 비용,
   구매 횟수 기반 비용 증가와 구매 실패 불변 조건을 구현한다.
2. 큰 범퍼 콤보 기준 도달과 잭팟에서 최대 1개의 전술 증원권을 획득하고, 다음 유닛
   Spawn 성공 시에만 무료 소환으로 소비하는 도메인 흐름을 구현한다.
3. 씬 배치 UI에 세 유닛 구매 카드와 `다음 유닛 무료` 상태를 연결하고, 유닛 역할과
   증원권 획득·소비 원인을 플레이 중 읽을 수 있게 만든다.
4. 자동 공 생산과 연속 전투를 10단계 보스까지 플레이해 유닛 선택 편중, Spawn 교착,
   증원권 유실과 게임 오버 정지 오류를 수정한다.
5. 런타임 계측 결과를 사용해 유닛별 비용, 콤보 기준, 생산, 전투, 잭팟, 적 성장과
   보스 수치를 한 성장축씩 조정한다.
6. 초당 예상 수익, 전선 위험도와 보스 진행을 기존 씬 배치 HUD에 최소 참조로
   표시한다.
7. 잭팟 전용 사운드, 다중 공과 방어선 도달 피드백을 보완하고 PC WebGL에서 성능과
   원인 가독성을 최종 확인한다.

각 단계는 기존 동작을 보존하는 별도 설계와 구현 계획을 승인받은 뒤 진행한다.

## 확정 사항

- 장르 방향은 능동형 방치 핀볼 디펜스다.
- 오프라인 보상은 없다.
- 공은 자동 순환만 사용하고 수동 발사 입력은 사용하지 않는다.
- 전투는 첫 웨이브부터 자동 시작한다.
- 핀볼과 전투는 동시에 계속 진행된다.
- 핀볼 보드와 전장은 상태 기반 카메라 전환 없이 같은 화면에 계속 표시한다.
- 도박성과 도파민은 핀볼 수익에 집중한다.
- 전투는 실시간 연속 디펜스이며 웨이브는 적 편성, 성장 수치와 보스 여부를 선택하는
  데이터 단위다.
- 일반 웨이브의 모든 적이 사망한 뒤 결과 화면이나 입력 잠금 없이 1~2초 후 다음
  웨이브가 자동 등장한다.
- 아군 전멸로 전투가 끊기지 않는다.
- 아군이 없어도 적은 방어선으로 계속 이동하고 플레이어는 새 아군을 즉시 투입해
  남은 적을 저지할 수 있다.
- 적은 방어선에 도달하면 사라지지 않고 반복 공격하며 새 아군이 다시 저지할 수 있다.
- 유닛 구매는 전사, 궁수, 마법사 중 현재 전선에 필요한 역할을 선택하는 방식이다.
- 같은 유닛의 반복 구매 비용은 해당 유닛의 구매 횟수에 따라 증가하며 다른 유닛의
  비용에는 영향을 주지 않는다.
- 큰 범퍼 콤보 기준 도달 또는 잭팟은 최대 1개의 전술 증원권을 지급한다.
- 전술 증원권은 다음 선택 유닛의 Spawn 성공 시에만 소비되며 해당 유닛을 무료로
  소환한다.
- 방어선 체력이 0이 되면 런을 종료하고 결과 화면에서 다시 시작하거나 타이틀로
  이동한다.
- 새 코어 루프와 호환되지 않는 구형 튜토리얼은 비활성화하고 후속 작업에서 다시
  설계한다.
- 첫 프로토타입은 단일 보드, 단일 전장과 10단계 보스까지 검증한다.
