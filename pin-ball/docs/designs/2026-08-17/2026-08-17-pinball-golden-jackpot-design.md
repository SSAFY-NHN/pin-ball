# 핀볼 황금 공·콤보 배수·잭팟 설계

## 목표

기존 자동 핀볼 생산을 유지하면서 황금 공, 공용 콤보 배수와 지정 특수 범퍼 잭팟을 추가한다. 잭팟이 없어도 기본 생산은 유지하며 물리, 자동 순환, 생산·전투 업그레이드는 변경하지 않는다.

## 구조

- `Pinball`이 `IsGolden`, `HasTriggeredJackpot` 활성 주기 상태를 소유한다.
- `PinballManager`가 영구 공 활성화마다 황금 여부를 독립 추첨하고 충돌 순서를 조율한다.
- `PinballComboController`가 공용 콤보와 실제 보상 배수를 계산한다.
- `PinballRewardController`가 정상 보상, 기존 GoldenBumper 추가 보상과 잭팟 추가 보상을 구분해 총액을 한 번 지급한다.
- `PinballObstacle.isJackpotBumper`로 기존 BigBumper 물리를 유지하면서 특수 범퍼를 지정한다.
- `PinballArcaneVfx`와 기존 골드 팝업을 재사용해 황금·잭팟 피드백을 표시한다.

## 확정 규칙

- 영구 공 활성화마다 `Mathf.Clamp01(goldenChance)`로 새 추첨한다. 기본값은 5%다.
- 복제 공은 추첨하지 않고 항상 일반 공이다.
- 회수, 풀 복귀, 새 활성화 때 황금·잭팟 상태와 외형을 초기화한다.
- 해당 충돌을 콤보에 먼저 등록하고 그 결과를 보상, UI와 잭팟 판정에 함께 쓴다.
- 콤보 배수는 기본값 기준 1~2회 x1, 3~4회 x1.5, 5회 이상 x2이며 x2가 상한이다.
- 정상 보상은 `범퍼 수익 × GoldenBall 아이템 배수 × 콤보 배수 × 황금 배수`를 `Mathf.RoundToInt`한다.
- GoldenBumper 아이템 추가 보상에는 콤보·황금 배수를 중복 적용하지 않는다.
- 잭팟은 영구 황금 공, 기준 콤보 이상, 지정 범퍼, 활성 주기 미발생 조건이 모두 맞을 때만 발생한다.
- 잭팟 추가 보상은 `기본값 + 범퍼 수익 × 잭팟 배수`이며 일반 충돌 배수를 재적용하지 않는다.
- 잭팟 발생 후 공은 계속 움직이며 같은 활성 주기에서는 다시 발생하지 않는다.

## 피드백

- 황금 공은 본체, trail, glow를 금색 계열로 표시하고 비활성화 때 원래 색으로 복원한다.
- 잭팟은 전용 `JACKPOT +골드` 팝업, 금백색 충돌 효과, 공과 범퍼의 강한 glow/punch로 구분한다.
- 기존 BumperHit SFX를 유지한다. 전용 SFX 에셋이 생기면 연결할 위치를 TODO로 남긴다.

## 제외

황금·잭팟 업그레이드, 다중 특수 범퍼, 외부 에셋·패키지, 저장 형식 변경, 물리 변경, 테스트 작성·실행은 포함하지 않는다.
