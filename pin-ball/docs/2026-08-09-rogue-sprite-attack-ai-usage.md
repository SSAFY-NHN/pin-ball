# Rogue 단검 제거 및 공격 애니메이션 AI 사용 기록

- 작업일: 2026-08-09
- 사용자 요청: `H_Rogue`의 화면 오른쪽 손에 든 단검을 제거하고, 수정된 캐릭터를 기준으로 몸 앞쪽에서 `준비 → 아래에서 위로 올려베기 → 회수` 공격 애니메이션을 효과 없이 스프라이트 형식으로 제작.
- 사용 도구: Codex, PixelLab MCP(`inpaint_image`, `animate_image`), Unity MCP(`import_asset`, `eval`, 에셋/콘솔 검증).
- AI 제안 및 적용 내용:
  - 84x84 원본의 화면 오른쪽 단검 영역만 16x12 마스크로 인페인팅하여 빈 장갑 손과 투명 배경을 복원.
  - 남은 단검 한 자루를 몸 앞쪽으로 옮긴 뒤 화면 오른쪽의 낮은 위치에서 얼굴 앞 위쪽으로 올려베고 기본 자세로 돌아오는 9프레임 공격 동작 생성. 잔상·발광·궤적·파티클은 제외.
  - PixelLab 후보 중 몸 앞쪽의 깨끗한 포즈만 `기본, 1, 2, 3, 5, 3, 2, 1, 기본` 순서로 선별해 공격과 회수가 몸 뒤로 넘어가지 않도록 구성.
  - 프레임을 756x84 가로 스프라이트 시트로 결합하고 84x84 셀 9개로 슬라이스.
  - 12fps 비루프 AnimationClip과 단일 `Attack` 기본 상태 AnimatorController 생성. 마지막 키는 첫 자세로 복귀.
- 실제 수정/생성 영역:
  - `Assets/03. Images/Humans/Rogue/H_Rogue.png`
  - `Assets/03. Images/Humans/Rogue/H_Rogue_Attack.png`
  - `Assets/05. Animations/Humans/Rogue/H_Rogue_Attack.anim`
  - `Assets/05. Animations/Humans/Rogue/H_Rogue_Attack.controller`
- 중요 프롬프트:
  - 단검 제거: 화면 오른쪽 손의 단검만 제거하고 빈 갈색 장갑 손과 자연스러운 팔 실루엣을 복원하며, 반대쪽 단검과 캐릭터·팔레트·픽셀 경계·투명 배경·마스크 밖 픽셀은 유지.
  - 공격 동작: 캐릭터는 화면 오른쪽을 바라보며 단검 손을 몸통 앞으로 넘긴 뒤, 화면 오른쪽 허리 아래에서 얼굴 앞 위쪽으로 짧게 올려베고 같은 앞쪽 경로를 역순으로 회수. 공격 프레임의 손과 단검은 몸통 중심보다 화면 오른쪽에 유지하고, 몸 뒤·머리 뒤·화면 왼쪽으로 베지 않음. 빈 손과 발의 지면선·캐릭터 중심을 유지하고 잔상·발광·베기 궤적·파티클·추가 무기는 금지.

  - 폐기한 초안 공격 작업 `08037910-3b59-490a-bd75-5685c9035842`, seed `240810`.
  - 몸 뒤로 올라가 폐기한 올려베기 작업 `7774b04b-71b4-49fa-b098-7f6a334600d5`, seed `240811`.
  - 흰 궤적과 뒤쪽 회수로 폐기한 전방 공격 작업 `80e0614a-5f7d-4b67-8f21-3a55098acc49`, seed `240812`.

## 2026-08-10 최종 방향 변경: 수평 그립과 전방 찌르기

- 사용자 요청: 원본부터 단검을 똑바로 잡는 자세로 수정하고, 베기 대신 전방 찌르기 애니메이션으로 교체.
- 적용 내용:
