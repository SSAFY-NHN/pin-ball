# 2단계 아군 전직 구현 AI 활용 기록

- 사용 AI: Codex, GPT-5 계열
- 사용자 요청: 신규 아군 이미지 리소스 적용, 4개 종족의 1차/2차 전직 트리와 직업별 스킬 재구현
- AI 제안: 리소스 이름과 직업 ID 통일, 레벨 5 분기 전직, 레벨 20 자동 2차 전직, 최대 레벨 30, 16개 전직 스킬 구성
- 실제 수정: 아군 JSON 데이터, 합성/전직 규칙, 스탯 성장 기준, 스킬 레지스트리와 16개 스킬, 대상 탐색, 초상화·사운드·공격 피드백, Game 씬 기본 ID, AllyUnit 프리팹의 20개 애니메이션 프로필
- 사용자 결정: 전 종족 적용, 최대 레벨 30, 직업 트리와 명칭, 기존 데이터/스킬 전면 재구축, 최소 테스트 우선
- 중요 지시: 기존 구조 보존, 사용자 변경 파일 보존, 빠른 구현을 위해 테스트 최소화
- 검증: Unity 컴파일 성공, 아군 데이터 20개/루트 4개/1차 8개/2차 8개/스킬 16개 확인, 핵심 합성 EditMode 테스트 12개 실행
- 제한: 전체 EditMode 및 플레이 테스트는 사용자 요청에 따라 생략. 스킬 계수는 초기 제안값이며 실제 플레이 후 밸런스 조정 필요
