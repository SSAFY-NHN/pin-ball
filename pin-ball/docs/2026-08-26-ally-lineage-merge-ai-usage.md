# 아군 계보 합성 AI 활용 기록

- 사용한 AI 도구/모델: OpenAI Codex, GPT-5 계열 모델
- 사용자 요청: 진화 유닛이 같은 계보의 하위 유닛 및 다른 진화 분기 유닛과 합성 가능하도록 변경
- AI 제안 내용: 같은 계보면 합성을 허용하고, 더 높은 진화 단계 또는 단계가 같으면 드롭 대상 직업을 결과로 유지
- AI 실제 수정 영역: `UnitMergeService`의 결과 직업 선택과 진화 후보 조회, 최소 EditMode 회귀 테스트
- 사용자 직접 결정/수정 필요 영역: 없음
- 중요한 프롬프트/지시: 서로 다른 진화 분기도 합성 허용, 테스트 최소화, 빠른 완료
- 테스트/검증 결과: Unity EditMode 테스트는 라이선스 초기화 지연으로 중단. 변경 diff 정적 검사 수행
